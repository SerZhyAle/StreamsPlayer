@@what-title
它是什么，为什么做它

@@what-p1
STREAMS Player 是一款独立的 Windows 桌面应用，用于网络广播、直播视频和 RTSP 网络摄像头。它会读取一份公开的精选流目录，因此首次运行就能得到一份可用的频道列表 - 之后您可以搜索、排序、置顶，也可以添加自己的频道，全部保存在您自己的机器上。

@@what-p2
它追求的是安静：播放器只做播放器该做的事。目录只在您要求时才更新，您手动添加和导入的流绝不会被更新覆盖，也不强制要求账户，没有广告、分析统计或作者运营的服务。您的电脑上运行的，只有您自己启动的东西。

@@use-title
如何使用

@@use-description
打开它，选一个频道 - 整个流程就是这样。可用安装程序，或从 Microsoft Store、winget 或便携版 ZIP 安装，也可以从源代码运行；还可以直接从命令行启动一个流。

@@use-1-title
从源代码运行

@@use-1-text
装好 .NET 10 SDK 后，在仓库根目录还原、生成并启动。

@@use-2-title
选择并播放

@@use-2-text
浏览目录，筛选或搜索，然后选择一个频道。广播在主窗口开始播放；视频和 RTSP 在播放器窗口中打开。普通启动不会播放任何内容；在[[glyph:app.settings]]设置中开启「启动时继续播放」，启动便会恢复上次关闭时正在播放的内容。

在 64 位查看器中，右键点击视频、音频文件或其文件夹并选择广播。Share Manager 导出 .spres 文件、二维码或快速链接，供 StreamsPlayer 导入。文件夹成为一个包含固定播放列表的频道；刷新会替换列表，撤销会停用链接。HTTP 网关有独立开关，默认关闭。每个令牌只允许读取一个广播，通常在 24 小时后过期。HTTP 未加密：请私下分享文档，仅在需要时启用互联网访问。

@@privacy-network-title
网络访问

@@privacy-network
应用程序仅在您执行操作时连接网络，且仅连接至该操作所需的目标：在导入目录或接受图片包时从 GitHub 下载的公共流媒体目录及可选预览包；您播放、录制或查看“关于频道”的流媒体提供商，或在网格模式下刷新预览的提供商；局域网内导入的 FastMediaSorter 手机或手表；以及仅在“设置”的“播放”页面请求时从第三方 GitHub 项目 (BtbN/FFmpeg-Builds) 下载的实验性 FlyleafLib 引擎可选 FFmpeg 库。每个请求均直达目标并受其政策约束；没有任何数据经过作者运行的服务。电视节目单仅在您于“设置”的“资料库”页面输入地址并点击“下载节目单”时下载一次，绝不在后台自动下载。 资料库设置中的可选交换来源通过 TLS 连接到您自己的服务器。注册时仅发送一次登录名和密码或配对码，之后发送设备身份、产品版本、接收能力及设备令牌。启用时保持一个控制连接，发送保活消息并自动重连；禁用后关闭连接。在媒体库设置中导入连接字符串或文件，也可粘贴或拖放到主窗口。它包含服务器地址和可选证书指纹，不含秘密。读取仅填写表单。每次注册输入密码或配对码前请检查地址；两者均不保存。提供的指纹必须匹配，无需信任提示。没有指纹时须在注册前批准服务器指纹；后续证书变更需要批准。无需本地代理或其他程序。 当广播通过您交换服务器的交换服务器并使用固定证书播放时，该流会经过 127.0.0.1 上的一个临时本地代理，该代理仅在广播播放期间存在，且只能从本设备访问。 广播：本应用可以将此电脑的四个来源直播发送 - 您选择的麦克风、电脑正在播放的声音、您选择的一整个显示器和您选择的一个摄像头，其中屏幕和摄像头在同一次广播中各可选择性地携带一路声音（麦克风或系统声音） - 发送到您自己账户的交换服务器或通过您的本地网络，且仅当您在设置中允许并亲自启动每个来源时才会发送；在此之前它是关闭的，关闭时不会采集任何内容，而当某个来源正在直播时，会显示一个带有停止按钮的可见指示器，并显示正在直播的显示器或摄像头的名称。视频为 H.264，最高 1280x720，每秒 30 帧，约 2 Mbit/s，由 Windows 自带的编码器生成；不添加任何组件。所选显示器上的所有内容都会被发送，包括通知和密码，受 Windows 保护的内容可能显示为空白。仅以访客身份登录某服务器的电脑不会广播。听众通过您启用的本地网络或交换服务器连接。您可以限制听众数量。本地网络上的每位听众和每条隧道都会占用此电脑的上传带宽；通过服务器的中继，此电脑只需为所有听众发送一份数据。您交给其他人的广播链接、文件或二维码包含标题、地址和打开广播的密钥，但绝不包含密码。您在设置中选择密码的生成方式：每次广播随机生成（默认）、由您设置（1 到 64 个字符，只保存在您 Windows 账户的 Windows 机密存储中），或无密码，此时任何拿到链接的人都可以观看和收听。广播期间更改会立即使之前的密码失效。实时指示器的“分享”菜单可复制链接、复制密码、将链接显示为供手机扫描的二维码，并保存描述文件。请将链接视为机密，仅与您选择的人分享。账户目录将这些密钥放在加密盒中。

在 64 位查看器中，右键点击视频、音频文件或其文件夹并选择广播。Share Manager 导出 .spres 文件、二维码或快速链接，供 StreamsPlayer 导入。文件夹成为一个包含固定播放列表的频道；刷新会替换列表，撤销会停用链接。HTTP 网关有独立开关，默认关闭。每个令牌只允许读取一个广播，通常在 24 小时后过期。HTTP 未加密：请私下分享文档，仅在需要时启用互联网访问。


@@privacy-exchange-title

@@privacy-exchange-private

@@privacy-exchange-honest
交换服务器负责连接您的设备，因此它知道您的账户、设备、文件夹和广播的名称，能看到哪些设备在线，以及传输了多少内容、何时传输。它无法打开经过它的内容：文件夹及其文件、广播和剪贴板都会在您的设备上加密，只能在您的其他设备上或由您授予访问权限的人打开。要查看其中的内容，运营服务器的人必须在您的账户中添加一台自己的设备，而它会出现在您的设备列表中。

@@privacy-exchange-sends
登录时，这台电脑只发送一次您的登录名和密码或配对码，然后发送设备标识、设备名称（STREAMS Player，而不是您电脑的名称）、产品、版本和平台（Windows）、角色、接收能力以及其加密密钥的公开部分。连接开启期间，服务器能看到此设备在线。广播时，它会收到广播的标题（屏幕和摄像头的标题会写明显示器或摄像头）、其为音频或视频的信息，以及在这台电脑上加密后才离开的音频或视频本身；私钥永远不会离开这台电脑。

@@privacy-exchange-broadcast

@@trust-what-title
“Windows 已保护你的电脑”

@@trust-what-1
这个界面是 Microsoft Defender SmartScreen（在英文版 Windows 上，标题为“Windows protected your PC”）。标题下方写着它“阻止了无法识别的应用启动”，点击“更多信息”后，发布者显示为“未知发布者”。当您打开一个从互联网下载、没有数字签名、而且 Windows 还没有在许多电脑上见过其运行的文件时，就会出现这个界面。

@@trust-what-2
这是针对一个 Windows 还不认识的文件的提醒，而不是说在文件里发现了什么 - 这也是 Windows 在尽职：它无法判断一个未签名的文件是谁制作的，所以在运行之前先问您。

@@trust-why-title
为什么这款应用会出现这个界面

@@trust-why-1
STREAMS Player 的安装程序、便携版 ZIP 和 winget 软件包都没有代码签名。代码签名证书每年要花费数百美元，对于一款没有任何收入的免费应用，我们目前选择不购买。这是一个决定，而不是疏忽 - 对于未签名的文件，发出警告正是 Windows 应该做的。

@@trust-why-2
SmartScreen 还会参考信誉：运行同一个文件且没有出问题的人越多，Windows 就越早认出它，警告也就不再出现。每次发布都是一个从零开始的新文件，所以更新之后警告可能再次出现，并会随着该版本被更多人使用而逐渐消失。

@@trust-why-3
Microsoft Store 版本由 Microsoft 签名，不会显示这个界面。每次 GitHub 发布也会在每个下载文件旁附上一个 .sha256 文件：在 PowerShell 中对您下载的文件运行 [[hash]]，结果应与该文件中的值一致。

@@support-stream
目录是一份公开的流列表，这些流由其他人运营：电台、广播机构、摄像头所有者。STREAMS Player 把它们的地址保存在您的设备上，并且如隐私页面所述，只在您操作时才连接网络；流本身仍由运营者掌握，因此一个流可能迁移、更改格式、只在另一个地区可用，或永久停播，目录也会随时间变化。频道出错时，“流不可用”窗口可能会视具体故障提供“重试”“复制报告”“隐藏”（对于您自己添加或导入的频道则是“删除”）和“保留”。具体出现哪些取决于故障：对于应用完全无法播放的地址，不会出现“重试”；没有网络连接时，不会出现“隐藏”或“删除”，因为此时并未连上该频道。“重试”会再试一次，您也可以直接打开另一个频道；“隐藏”会把该频道从您的列表中移除，您可以把它找回来：在“设置”的“媒体库”页面中点击“已隐藏”，再点击该频道旁边的“取消隐藏”；“复制报告”会把一段简短的说明放到剪贴板，供您粘贴到 issue 中，应用本身不会发送任何内容。“操作”菜单中的“从互联网导入频道”会下载当前的目录，而且只在您要求时才下载。流消失并不是应用的故障，也不承诺会修复。
