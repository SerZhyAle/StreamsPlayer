@@what-title
Что это и зачем

@@what-p1
Трансляции - независимое приложение для Windows для интернет-радио, live-видео и сетевых RTSP-камер. Оно читает готовый публичный каталог потоков, поэтому рабочий список каналов доступен сразу при первом запуске. Дальше вы ищете, сортируете, закрепляете и добавляете свои каналы - всё хранится локально на вашем устройстве.

@@what-p2
Смысл - в спокойствии: плеер остаётся плеером. Каталог обновляется только по вашей команде, добавленные вручную и импортированные потоки никогда не перезаписываются обновлением, а аккаунта, рекламы, аналитики и авторского сервиса нет вовсе. На вашем ПК работает только то, что вы запустили.

@@privacy-network-title
Доступ к сети

@@privacy-network
Приложение подключается к сети только по вашему действию и только туда, куда необходимо для этого действия: к общедоступному каталогу трансляций и предлагаемому вслед за ним набору картинок предпросмотра, скачиваемым с GitHub при импорте каталога или принятии набора; к источнику трансляции, которую вы воспроизводите, записываете или для которой открываете карточку «О канале», либо чей видеокадр обновляется в режиме сетки; к телефону или часам FastMediaSorter, которые вы импортировали, напрямую в вашей локальной сети; и, только если вы запросите их в «Настройках» на вкладке «Воспроизведение», к необязательным библиотекам FFmpeg для экспериментального движка FlyleafLib, скачиваемым из стороннего проекта на GitHub (BtbN/FFmpeg-Builds). Каждый запрос идёт напрямую к месту назначения и подчиняется его правилам; ни один запрос не проходит через службы автора приложения. @@privacy-local-title
Локальные данные

@@privacy-local
Трансляции хранит состояние каталога, добавленные и импортированные вами каналы, закрепления, подборки, скрытые каналы, историю прослушивания, отметки воспроизведения, кадры предпросмотра в пределах 150 МБ, необязательные библиотеки FFmpeg, если вы их скачали, и журналы диагностики десяти последних запусков в [[appdata]]. Записи и сохранённые кадры попадают в выбранные вами папки, а по умолчанию - в Recordings в «Видео», Recordings в «Музыке» и Frames в «Изображениях». Эти данные остаются на устройстве, пока вы сами не скопируете или не сохраните их резервную копию - либо пока вы не воспользуетесь кнопкой «Отправить журналы автору» в «Настройках» на вкладке «О программе», которая упаковывает эти журналы диагностики вместе с версией приложения, версией Windows и настройками в архив и открывает вашу почтовую программу, чтобы вы прикрепили его и отправили на [[email]]. Архив создаётся только по нажатию этой кнопки, в журналах названы потоки, которые воспроизводились, и ничего не отправляется без того, чтобы вы сами нажали «Отправить» в своей почтовой программе. Там же хранятся загруженная телепрограмма и выбранные вами каналы программы; «Удалить программу» в «Настройках» удаляет и то и другое.

@@trust-eyebrow
Трансляции · Установка

@@trust-title
Windows вас предупредила. Вот что это значит.

@@trust-intro
Трансляции - бесплатное приложение независимого разработчика. Если Windows остановила его, когда вы впервые открыли скачанный файл, здесь написано, что это за окно, почему оно появилось, что именно нажать и чего приложение никогда не делает. Чтение займёт около тридцати секунд.

@@trust-what-title
«Система Windows защитила ваш компьютер»

@@trust-what-1
Это окно фильтра Microsoft Defender SmartScreen; в английской Windows его заголовок - «Windows protected your PC». Под заголовком сказано, что фильтр «предотвратил запуск неопознанного приложения», а после «Подробнее» издатель назван «Неизвестный издатель». Окно появляется, когда вы открываете скачанный из интернета файл без цифровой подписи, который Windows ещё не видела запущенным на многих компьютерах.

@@trust-what-2
Это осторожность в отношении файла, который Windows пока не знает, а не сообщение о чём-то найденном внутри него - и Windows здесь делает свою работу: она не может определить, кто сделал неподписанный файл, поэтому спрашивает вас перед запуском.

@@trust-why-title
Почему оно появляется для этого приложения

@@trust-why-1
Установщик, портативный ZIP и пакет winget приложения Трансляции не подписаны цифровой подписью. Сертификат для подписи кода стоит сотни долларов в год, и для бесплатного приложения без дохода мы пока решили его не покупать. Это решение, а не недосмотр, и для неподписанного файла Windows должна показывать именно такое предупреждение.

@@trust-why-2
SmartScreen учитывает и репутацию: чем больше людей без проблем запускают один и тот же файл, тем скорее Windows его узнаёт и перестаёт предупреждать. Каждый выпуск - новый файл, который начинает с нуля, поэтому предупреждение может вернуться после обновления и пропадает по мере того, как выпуском пользуются.

@@trust-why-3
Версия из Microsoft Store подписана Microsoft и такого окна не показывает. Кроме того, каждый релиз на GitHub публикует рядом с каждым файлом загрузки файл .sha256: выполните [[hash]] в PowerShell для скачанного файла - результат должен совпасть со значением в этом файле.

@@trust-click-title
Что нажать

@@trust-click-intro
В окне «Система Windows защитила ваш компьютер» (Windows protected your PC):

@@trust-click-1
Нажмите «Подробнее» (More info) под сообщением.

@@trust-click-2
Убедитесь, что имя файла - это скачанный вами файл StreamsPlayer, и нажмите «Выполнить в любом случае» (Run anyway).

@@trust-click-3
Вот и всё - установщик или приложение из ZIP запустится как обычно. Отключать SmartScreen или антивирус никогда не нужно, а самому приложению никогда не нужны права администратора.

@@trust-admin-title
«Разрешить этому приложению от неизвестного издателя вносить изменения на вашем устройстве?»

@@trust-admin-1
Обычно вы этого запроса не увидите. По умолчанию установщик ставит приложение только для вас, в [[installdir]], и прав администратора для этого не требует. Если он спросит, как устанавливать, выберите установку только для себя (Install for me only).

@@trust-admin-2
Windows показывает этот запрос, только если выбрать установку для всех пользователей (Install for all users). Тогда установщик использует права администратора ровно для трёх вещей:

@@trust-admin-item-1
копирует программу в папку Program Files, чтобы её могла запускать любая учётная запись на этом компьютере;

@@trust-admin-item-2
добавляет ярлык STREAMS Player в меню «Пуск» каждой учётной записи и на общий рабочий стол, если вы отметили этот пункт;

@@trust-admin-item-3
регистрирует приложение в Windows как установленное, чтобы его можно было потом удалить.

@@trust-admin-3
Одно действие убирает всё это сразу: Параметры > Приложения > Установленные приложения (в Windows 10 - «Приложения и возможности») > STREAMS Player > Удалить. Если не хотите давать права администратора, нажмите «Нет» и запустите установщик снова, выбрав установку только для себя.

@@trust-av-title
Если антивирус задержал файл

@@trust-av
Некоторые антивирусы с осторожностью относятся к новым неподписанным файлам. Если ваш поместил Трансляции в карантин, восстановите файл и добавьте исключение только для его папки - [[installdir]] для установщика или папки, куда вы распаковали ZIP. Исключения для одной этой папки достаточно, и его можно убрать в любой момент; не выключайте антивирус.

@@trust-never-title
Чего приложение никогда не делает

@@trust-never-1
Ему никогда не нужны права администратора ни для установки, ни для работы; оно никогда не добавляет себя в автозагрузку Windows и не устанавливает фоновых служб.

@@trust-never-2
В нём нет аккаунта, рекламы, аналитики и телеметрии, и нет сервиса автора, через который проходили бы ваши данные.

@@trust-never-3
Оно подключается к сети только при вашем действии и только для того, что требуется этому действию: к общедоступному каталогу трансляций и набору картинок на GitHub, к источнику трансляции, которую вы воспроизводите, записываете или просматриваете, к телефону или часам FastMediaSorter в вашей локальной сети и к необязательным библиотекам FFmpeg, если вы запросите их в «Настройках». Телепрограмма загружается только по адресу, который вы ввели сами, и только когда вы нажимаете «Скачать программу».
@@trust-never-4
Оно никогда не скачивает каталог само - обновление происходит, только когда вы его запросите.

@@trust-never-5
Оно никогда само не отправляет ваши данные или журналы куда бы то ни было. Кнопка «Отправить журналы автору» на вкладке «О программе» в «Настройках» только подготавливает архив и письмо в вашей почтовой программе; ничего не отправляется, пока вы сами не нажмёте «Отправить».
@@trust-never-6
Удаление приложения никогда не стирает ваши каналы, закреплённые станции и историю - они остаются в [[appdata]], пока вы сами не удалите эту папку.
