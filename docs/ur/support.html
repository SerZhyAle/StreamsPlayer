کچھ کام نہیں کر رہا؟ اس کی اطلاع اس طرح دیں۔

STREAMS Player ایک آزاد ڈیولپر نے بنایا ہے۔ یہ صفحہ بتاتا ہے کہ رپورٹ میں کیا لکھنا چاہیے، اسے کہاں بھیجنا ہے، اور اس کے بعد آپ کیا توقع رکھ سکتے ہیں۔

بگ کی اطلاع دیں

GitHub پر ایک Issue کھولیں۔ فارم پوچھتا ہے کہ کیا ہوا، کن مراحل کے بعد ہوا، STREAMS Player کا ورژن اور Windows کا ورژن کیا ہے۔ ایپ کا ورژن آپ کو ترتیبات کی ونڈو میں ‘کے بارے میں’ صفحے پر ملتا ہے۔ اگر کوئی خاص چینل شامل ہو تو اس کا نام لکھیں۔ Issue کے لیے مفت GitHub اکاؤنٹ چاہیے؛ اگر آپ کے پاس نہیں ہے تو اس صفحے پر آگے دیا گیا پتا استعمال کریں۔

GitHub پر اطلاع دیں

لاگ بھیج کر مسئلے کی اطلاع دیں

ہیڈر میں گیئر بٹن سے، یا ‘کارروائیاں’ مینو میں ‘لائبریری ترتیبات’ کے اندراج سے ترتیبات کھولیں اور ‘کے بارے میں’ صفحے پر ‘لاگ مصنف کو بھیجیں’ دبائیں۔ ایپ آپ کے ورژن، ونڈوز اور ترتیبات کے مختصر خلاصے کے ساتھ آخری دس آغاز کے تشخیصی لاگز کو ‘فائلیں’ صفحے پر ‘فریموں کا فولڈر’ میں منتخب کردہ فولڈر میں پیک کرتی ہے (اگر اسے خالی چھوڑا ہو تو ڈاؤن لوڈز میں)، پھر تیار پیغام کے ساتھ آپ کا ای میل پروگرام کھولتی ہے۔ تصدیق مکمل راستہ دکھاتی ہے اور آپ کے کہنے پر فولڈر کھول سکتی ہے؛ آپ آرکائیو منسلک کر کے خود بھیجیں دباتے ہیں۔

کوئی چینل چلنا بند ہو جائے

عوامی فہرست ان نشریات پر مشتمل ہے جنہیں دوسرے لوگ چلاتے ہیں: ریڈیو اسٹیشن، نشریاتی ادارے، کیمروں کے مالک۔ STREAMS Player ان کے پتے آپ کے آلے پر رکھتا ہے اور، جیسا کہ رازداری کا صفحہ بتاتا ہے، نیٹ ورک سے صرف اس وقت جڑتا ہے جب آپ عمل کرتے ہیں؛ نشریات خود اپنے مالک کے پاس رہتی ہے، اس لیے کوئی نشریات منتقل ہو سکتی ہے، فارمیٹ بدل سکتی ہے، صرف کسی دوسرے خطے میں دستیاب ہو سکتی ہے یا ہمیشہ کے لیے بند ہو سکتی ہے، اور یہ فہرست وقت کے ساتھ بدلتی رہتی ہے۔ جب کوئی چینل ناکام ہو تو ‘نشریات دستیاب نہیں’ ونڈو ان میں سے کچھ پیش کر سکتی ہے: ‘دوبارہ کوشش’، ‘رپورٹ نقل کریں’، ‘چھپائیں’ (اپنے شامل یا درآمد کردہ چینل کے لیے ‘حذف کریں’) اور ‘رکھیں’۔ ان میں سے کیا نظر آئے گا یہ ناکامی کی نوعیت پر منحصر ہے: ایسے پتے کے لیے جسے ایپ بالکل چلا نہیں سکتی ‘دوبارہ کوشش’ نظر نہیں آتا، اور نیٹ ورک کنکشن نہ ہو تو ‘چھپائیں’ یا ‘حذف کریں’ نظر نہیں آتا، کیونکہ چینل تک اس وقت پہنچا ہی نہیں گیا تھا۔ ‘دوبارہ کوشش’ پھر آزماتا ہے، یا آپ بس کوئی دوسرا چینل کھول سکتے ہیں؛ ‘چھپائیں’ چینل کو آپ کی فہرست سے ہٹا دیتا ہے، اور آپ اسے واپس لا سکتے ہیں: ‘ترتیبات’ میں ‘لائبریری’ کے صفحے پر ‘چھپے ہوئے’ دبائیں، پھر چینل کے ساتھ ‘دکھائیں’؛ ‘رپورٹ نقل کریں’ کلپ بورڈ پر ایک مختصر نوٹ رکھ دیتا ہے جسے آپ Issue میں پیسٹ کر سکتے ہیں، اور ایپ کچھ نہیں بھیجتی۔ ‘کارروائیاں’ مینو میں ‘انٹرنیٹ سے چینلز درآمد کریں’ موجودہ فہرست ڈاؤن لوڈ کرتا ہے، اور صرف اسی وقت جب آپ کہیں۔ جو نشریات ختم ہو چکی ہو وہ ایپ کی خرابی نہیں ہے، اور اس کے ٹھیک ہونے کا وعدہ نہیں کیا جاتا۔

Windows نے تنبیہ کی

اگر Windows نے انسٹالر کو ‘Windows protected your PC’ (Windows نے آپ کے PC کو محفوظ رکھا) اسکرین کے ساتھ روک دیا، تو یہ Microsoft Defender SmartScreen ہے جو ایسی فائل پر ردِ عمل دے رہا ہے جسے وہ ابھی نہیں جانتا۔ یہ فائل کے اندر کسی چیز کے ملنے کی اطلاع نہیں ہے۔ ‘انسٹال میں مدد’ کا صفحہ بتاتا ہے کہ اس اسکرین کا کیا مطلب ہے اور ٹھیک کہاں کلک کرنا ہے۔
