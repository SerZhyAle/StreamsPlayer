STREAMS Player · انسٹال کرنا

Windows نے آپ کو تنبیہ کی۔ اس کا مطلب یہ ہے۔

STREAMS Player ایک آزاد ڈیولپر کی مفت ایپ ہے۔ اگر ڈاؤن لوڈ کی گئی فائل پہلی بار کھولتے وقت Windows نے اسے روک دیا، تو یہ صفحہ بتاتا ہے کہ وہ اسکرین کیا ہے، کیوں ظاہر ہوتی ہے، ٹھیک کہاں کلک کرنا ہے، اور ایپ کیا کبھی نہیں کرتی۔ اسے پڑھنے میں تقریباً تیس سیکنڈ لگتے ہیں۔

”Windows protected your PC“ (Windows نے آپ کے PC کو محفوظ رکھا)

یہ اسکرین Microsoft Defender SmartScreen ہے؛ انگریزی Windows پر اس کا عنوان ”Windows protected your PC“ ہوتا ہے، اور اگر آپ کا Windows اردو میں ہو تو متن ترجمہ شدہ نظر آ سکتا ہے۔ عنوان کے نیچے لکھا ہوتا ہے کہ اس نے ”prevented an unrecognized app from starting“ (ایک غیر شناخت شدہ ایپ کو شروع ہونے سے روک دیا)، اور ”More info“ (مزید معلومات) کے بعد ناشر کا نام ”Unknown publisher“ (نامعلوم ناشر) بتایا جاتا ہے۔ یہ اس وقت ظاہر ہوتی ہے جب آپ انٹرنیٹ سے ڈاؤن لوڈ کی گئی ایسی فائل کھولتے ہیں جس پر ڈیجیٹل دستخط نہیں اور جسے Windows نے ابھی بہت سے PC پر چلتے نہیں دیکھا۔

یہ ایک ایسی فائل کے بارے میں احتیاط ہے جسے Windows ابھی نہیں جانتا، اس کے اندر کچھ ملنے کی اطلاع نہیں - اور یہ Windows کا اپنا کام کرنا ہے: وہ نہیں بتا سکتا کہ بغیر دستخط والی فائل کس نے بنائی، اس لیے چلانے سے پہلے آپ سے پوچھتا ہے۔

یہ اس ایپ کے لیے کیوں ظاہر ہوتی ہے

STREAMS Player کا انسٹالر، پورٹیبل ZIP اور winget پیکیج کوڈ پر دستخط شدہ نہیں ہیں۔ کوڈ سائننگ سرٹیفکیٹ پر ہر سال سینکڑوں ڈالر خرچ ہوتے ہیں، اور بغیر کسی آمدنی والی مفت ایپ کے لیے ہم نے فی الحال اسے نہ خریدنے کا فیصلہ کیا ہے۔ یہ ایک فیصلہ ہے، کوتاہی نہیں - اور بغیر دستخط والی فائل کے لیے تنبیہ بالکل وہی ہے جو Windows کو دکھانی چاہیے۔

SmartScreen ساکھ کو بھی دیکھتا ہے: جتنے زیادہ لوگ ایک ہی فائل کو بغیر کسی مسئلے کے چلاتے ہیں، Windows اتنی جلدی اسے پہچان لیتا ہے اور تنبیہ رک جاتی ہے۔ ہر ریلیز ایک نئی فائل ہے جو صفر سے شروع ہوتی ہے، اسی لیے اپ ڈیٹ کے بعد تنبیہ واپس آ سکتی ہے اور اسی لیے ریلیز کے استعمال کے ساتھ وہ مدھم پڑ جاتی ہے۔

Microsoft Store والا ورژن Microsoft کا دستخط شدہ ہے اور یہ اسکرین نہیں دکھاتا۔ ہر GitHub ریلیز میں ہر ڈاؤن لوڈ کے ساتھ ایک .sha256 فائل بھی شائع ہوتی ہے: ڈاؤن لوڈ کی گئی فائل پر PowerShell میں Get-FileHash -Algorithm SHA256 <file> چلائیں، اور نتیجہ اُس فائل میں موجود قدر سے ملنا چاہیے۔

کہاں کلک کریں

”Windows protected your PC“ (Windows نے آپ کے PC کو محفوظ رکھا) والی اسکرین پر:

  1. پیغام کے نیچے ”More info“ (مزید معلومات) پر کلک کریں۔
  2. تسلی کر لیں کہ فائل کا نام وہی STREAMS Player فائل ہے جو آپ نے ڈاؤن لوڈ کی تھی، پھر ”Run anyway“ (پھر بھی چلائیں) پر کلک کریں۔

بس اتنا ہی - انسٹالر، یا ZIP والی ایپ، معمول کے مطابق شروع ہو جاتی ہے۔ آپ کو کبھی SmartScreen بند کرنے یا اپنا اینٹی وائرس غیر فعال کرنے کی ضرورت نہیں، اور ایپ کو خود کبھی منتظم کے اختیارات کی ضرورت نہیں ہوتی۔

”Do you want to allow this app from an unknown publisher to make changes to your device?“ (کیا آپ نامعلوم ناشر کی اس ایپ کو اپنے آلے میں تبدیلیاں کرنے کی اجازت دینا چاہتے ہیں؟)

عام طور پر آپ کو یہ پیغام نظر نہیں آنا چاہیے۔ بطور ڈیفالٹ انسٹالر صرف آپ کے لیے، %LOCALAPPDATA%\Programs\StreamsPlayer میں انسٹال کرتا ہے، اور اس کے لیے اسے منتظم کے اختیارات کی ضرورت نہیں۔ اگر وہ پوچھے کہ کیسے انسٹال کرنا ہے، تو ”Install for me only (recommended)“ (صرف میرے لیے انسٹال کریں - تجویز کردہ) منتخب کریں۔

Windows یہ پیغام صرف اُس وقت دکھاتا ہے جب آپ ”Install for all users“ (تمام صارفین کے لیے انسٹال کریں) منتخب کریں۔ تب انسٹالر منتظم کے اختیارات صرف تین کاموں کے لیے استعمال کرتا ہے:

  • پروگرام کو Program Files فولڈر میں کاپی کرنا، تاکہ اس PC کا ہر اکاؤنٹ اسے چلا سکے؛
  • STREAMS Player کو ہر اکاؤنٹ کے Start مینو میں شامل کرنا، اور مشترکہ ڈیسک ٹاپ پر بھی اگر آپ نے وہ اختیار منتخب کیا ہو؛
  • اسے Windows میں انسٹال شدہ ایپ کے طور پر درج کرنا، تاکہ بعد میں اسے ہٹایا جا سکے۔

ایک ہی عمل تینوں کو ایک ساتھ ہٹا دیتا ہے: Settings > Apps > Installed apps (ترتیبات > ایپس > انسٹال شدہ ایپس؛ Windows 10 پر Apps & features) کھولیں، STREAMS Player منتخب کریں اور Uninstall (ان انسٹال) دبائیں۔ اگر آپ منتظم کے اختیارات نہیں دینا چاہتے، تو ”No“ (نہیں) پر کلک کریں اور انسٹالر کو ”Install for me only“ کے ساتھ دوبارہ چلائیں۔

اگر آپ کا اینٹی وائرس فائل کو روک لے

کچھ اینٹی وائرس پروگرام نئی، بغیر دستخط والی فائلوں کے ساتھ محتاط ہوتے ہیں۔ اگر آپ کا اینٹی وائرس STREAMS Player کو قرنطینہ میں ڈال دے، تو اسے بحال کریں اور صرف اس کے فولڈر کے لیے استثنا شامل کریں - انسٹالر کے لیے %LOCALAPPDATA%\Programs\StreamsPlayer، یا وہ فولڈر جس میں آپ نے ZIP کھولا تھا۔ صرف اسی ایک فولڈر کا استثنا کافی ہے، اور آپ اسے کسی بھی وقت ہٹا سکتے ہیں؛ اپنا اینٹی وائرس بند نہ کریں۔

STREAMS Player کیا کبھی نہیں کرتا

  • اسے انسٹال ہونے یا چلنے کے لیے کبھی منتظم کے اختیارات کی ضرورت نہیں ہوتی، یہ خود کو کبھی Windows کے آغاز (startup) میں شامل نہیں کرتا، اور کوئی پس منظر سروس انسٹال نہیں کرتا۔
  • اس میں کوئی اکاؤنٹ، اشتہار، تجزیات یا ٹیلی میٹری نہیں، اور مصنف کی چلائی ہوئی کوئی ایسی سروس نہیں جس سے ہو کر آپ کا ڈیٹا گزرے۔
  • یہ صرف آپ کے کسی عمل پر نیٹ ورک سے جڑتا ہے، اور صرف اُسی سے جس کی اس عمل کو ضرورت ہو: GitHub پر عوامی نشریاتی فہرست اور اس کا اختیاری پیش منظر پیکیج، اُن نشریات کا فراہم کنندہ جنہیں آپ چلاتے، ریکارڈ کرتے یا جن کا پیش منظر دیکھتے ہیں، آپ کے اپنے نیٹ ورک پر FastMediaSorter والا فون یا گھڑی، اور اختیاری FFmpeg لائبریریاں اگر آپ ”اوزار“ میں ان کی درخواست کریں۔
  • یہ فہرست کو کبھی خود سے ڈاؤن لوڈ نہیں کرتا - تازہ کاری صرف اُس وقت ہوتی ہے جب آپ کہیں۔
  • یہ آپ کا ڈیٹا یا لاگ کبھی خود سے کہیں نہیں بھیجتا۔ ”اوزار“ میں ”لاگ مصنف کو بھیجیں“ صرف ایک زپ فائل اور آپ کے اپنے میل پروگرام میں ایک پیغام تیار کرتا ہے؛ جب تک آپ وہاں بھیجیں نہ دبائیں، کچھ بھی باہر نہیں جاتا۔
  • اسے ان انسٹال کرنے سے آپ کے چینل، پن یا تاریخچہ کبھی حذف نہیں ہوتے - وہ %LOCALAPPDATA%\StreamsPlayer میں رہتے ہیں جب تک آپ خود وہ فولڈر نہ ہٹائیں۔
