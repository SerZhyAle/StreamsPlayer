بطورِ طے شدہ نجی۔

عام پلے بیک کے لیے اکاؤنٹ ضروری نہیں۔ اختیاری ایکسچینج اکاؤنٹ آپ کے اپنے سرور کا ہے۔ کوئی اشتہار، تجزیات، ٹیلی میٹری یا مصنف کی چلائی ہوئی سروس نہیں۔

نیٹ ورک تک رسائی

ایپلیکیشن صرف آپ کے عمل پر اور صرف اسی جگہ سے رابطہ کرتی ہے جہاں اس عمل کی ضرورت ہوتی ہے: درآمد کرتے وقت GitHub سے عوامی اسٹریم کیٹلاگ اور اختیاری پیش نظارہ پیک؛ جس اسٹریم کو آپ چلاتے ہیں، ریکارڈ کرتے ہیں یا چینل کی تفصیل کھولتے ہیں اس کا فراہم کنندہ؛ مقامی نیٹ ورک پر FastMediaSorter ڈیوائس؛ اور صرف اگر آپ ترتیبات میں ‘پلے بیک’ صفحے پر طلب کریں، تو FlyleafLib انجن کے لیے اختیاری FFmpeg لائبریریاں (BtbN/FFmpeg-Builds)۔ ہر درخواست براہ راست منزل پر جاتی ہے؛ مصنف کی کسی سروس سے کچھ نہیں گزرتا۔ ٹی وی شیڈول صرف اس پتے سے ڈاؤن لوڈ ہوتا ہے جو آپ ترتیبات کے ‘لائبریری’ صفحے پر خود درج کرتے ہیں، ‘شیڈول ڈاؤن لوڈ کریں’ دبانے پر ایک بار، اور کبھی بھی پس منظر میں نہیں۔ لائبریری کی ترتیبات میں اختیاری ایکسچینج ماخذ TLS کے ذریعے آپ کے سرور سے جڑتا ہے۔ رجسٹریشن کے لیے لاگ ان اور پاس ورڈ یا جوڑا بنانے کا کوڈ ایک بار بھیجتا ہے، پھر آلے کی شناخت، پروڈکٹ ورژن، وصول کرنے کی صلاحیتیں اور ٹوکن بھیجتا ہے۔ فعال ہونے پر سرگرمی کے پیغامات اور دوبارہ رابطے کے ساتھ ایک کنٹرول کنکشن رکھتا ہے؛ بند کرنے پر رابطہ ختم ہوتا ہے۔ ہر سرٹیفکیٹ کو واضح منظوری چاہیے، تجدید کے بعد بھی۔

یہ ویب سائٹ

یہ حصہ ویب سائٹ کے بارے میں ہے، ایپلی کیشن کے بارے میں نہیں۔ ہر صفحہ اپنے فونٹس Google Fonts سے لوڈ کرتا ہے: آپ کا براؤزر fonts.googleapis.com سے اسٹائل شیٹ اور fonts.gstatic.com سے فونٹ فائلیں طلب کرتا ہے، اس لیے Google کو آپ کا IP ایڈریس، براؤزر کی معلومات اور اس صفحے کا پتا ملتا ہے جو آپ پڑھ رہے ہیں۔ ہوم پیج ایک بار api.github.com سے تازہ ترین ریلیز بھی دریافت کرتا ہے تاکہ انسٹالر کا بٹن موجودہ فائل کی طرف اشارہ کرے؛ GitHub کو آپ کا IP ایڈریس اور براؤزر کی معلومات ملتی ہیں۔ صفحات خود GitHub Pages (serzhyale.github.io) سے فراہم کیے جاتے ہیں۔ سائٹ پر کوئی اینالیٹکس، اشتہار یا ٹریکنگ نہیں ہے، یہ کوئی کوکی سیٹ نہیں کرتی، اور آپ کے براؤزر کے لوکل اسٹوریج میں صرف تھیم اور زبان کا انتخاب رکھتی ہے۔ ان میں سے ہر سروس اپنی پالیسی کے تابع ہے؛ کوئی بھی مصنف کی چلائی ہوئی نہیں ہے۔

مقامی معلومات

STREAMS Player کیٹلاگ کی حالت، آپ کے شامل اور درآمد کردہ چینلز، پنز، مجموعے، پوشیدہ چینلز، سننے کی تاریخ، 150 MB کے اندر پیش نظارہ فریمز، اختیاری FFmpeg لائبریریاں اور آخری دس سیشنز کے تشخیصی لاگز کو %LOCALAPPDATA%\StreamsPlayer کے تحت محفوظ کرتا ہے۔ ریکارڈنگز اور فریمز منتخب فولڈرز میں جاتے ہیں (ڈیفالٹ ویڈیوز، میوزک اور پکچرز)۔ یہ ڈیٹا آپ کے آلے پر رہتا ہے الا یہ کہ آپ ترتیبات میں ‘کے بارے میں’ صفحے پر ‘مصنف کو لاگز بھیجیں’ کا استعمال کرتے ہوئے اسے serzhyale@gmail.com پر بھیجیں۔ ڈاؤن لوڈ کردہ ٹی وی شیڈول بھی وہاں رہتا ہے؛ ترتیبات میں ‘شیڈول ہٹائیں’ دونوں کو حذف کر دیتا ہے۔ پاس ورڈ اور کوڈ مٹا دیے جاتے ہیں۔ اکاؤنٹ، ٹوکن اور فنگرپرنٹ الگ فائل میں آپ کے Windows صارف کے لیے محفوظ رہتے ہیں؛ اکاؤنٹ ہٹانے پر مٹ جاتے ہیں۔ تشخیصی آرکائیو میں وہ فائل شامل نہیں ہوتی اور اکاؤنٹ کی معلومات چھپا دی جاتی ہیں۔ ایکسچینج رابطہ صرف آپ کی واضح ماخذ ترتیب کے بعد شروع ہوتا ہے۔
