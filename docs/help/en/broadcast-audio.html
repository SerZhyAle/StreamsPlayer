Live broadcast, audio

Each incoming audio broadcast has this small window to itself. It shows the broadcast's title and state, has its own volume, and lets you stop the broadcast, record it and listen again. The window is titled with the broadcast's own title, so every broadcast window reads differently, but they all look like this. Several can be open together, beside the main window and beside one another. Closing a window, with Esc or the close box or Close, stops that broadcast and nothing else.

In this order

  1. Read State line under the title: it shows whether the broadcast is connecting, playing, reconnecting, ended, failed or stopped.
  2. Set the level with Audio volume, or tick Mute. Both change this broadcast only.
  3. While the state is playing, press Record to save what you hear to a file; press it again to stop and save.
  4. Press Stop to stop listening. When the window is not listening, Reconnect takes its place so that you can listen again.
  5. If the broadcast failed, open Details to read the failure code. If Check the connection is offered, press it to check the connection.
  6. Close the window when you are done: that ends the listening to this broadcast and nothing else.

The elements

State lineSays what this broadcast is doing, or why it is not.

The line under the title shows the state - connecting, playing, reconnecting, ended, failed or stopped - and, for some conditions, a message beside it. When the state is ended, the line is the sentence "The broadcast has ended." When the broadcast failed, the line gives the message for the failure: it says what happened, and where there is something to try, that follows on the next line.

Next
Depending on the state, the buttons below change: Stop while the window is listening, Reconnect or Play when it is not.
DetailsShows the code of a failure.

Appears under the state line only when the broadcast failed for a reason that has a code. Expand it to read the line that starts with "Code:". The code is the short name of the failure.

Audio volumeSets the volume of this broadcast only.

The slider starts at the audio volume the main window is set to. Moving it changes this broadcast and nothing else: the volume of the main window, the other broadcasts and the saved setting stay as they are, and the level is not kept after this window closes.

A click on the slider jumps straight to that level.

Why
To balance a broadcast against the station playing in the main window or against other broadcasts.
MuteSilences this broadcast without moving the slider.

While it is ticked, this broadcast plays at zero. The slider keeps its position, so clearing the tick returns to the same level. It affects this broadcast only.

Undo
Clear the tick.
RecordSaves what this broadcast plays to a file.

The button shows only an icon; hover over it to read its name. Recording starts only while the state is playing. While it records, the button becomes Stop recording, and the line under the slider counts the length of the recording.

When the format of the broadcast cannot be recorded, the button is unavailable and its tooltip says "This station's stream format cannot be recorded".

Press the button again to end the recording and save the file: the line says that it is saving, then names the file and its length. Recordings go to the radio recordings folder, which is set on the Files page of Settings and is the Recordings folder in Music when none is chosen. If a folder cannot be written, the line says so and the recording goes to another folder; if writing fails, the recording stops and the line says it could not write to that folder. If nothing was recorded, the line says so.

Why
To keep a broadcast you want to hear again.
Undo
A saved recording is a file in the folder; delete it there if you do not want it.
Shortcut
R does the same from anywhere in the window.
ReconnectListens to the broadcast again.

Shown while the window is not listening: after Stop, after the broadcast has ended, and after a failure. When the state is ended it reads Reconnect; in the other cases it reads Play.

Next
The state line shows how the new attempt goes.
Check the connectionOpens the connection check for a broadcast that could not be kept.

Shown when the broadcast failed in a way the window can only describe as unavailable, and a server to check is known. A failure that already says what to do, such as a refused password or a certificate that does not match, does not offer it.

Next
The Connection check window opens in front of this one, with the first line naming the broadcast; this window waits until you close it.
StopStops listening to this broadcast.

Shown while the window is connecting, playing or reconnecting. The window stays open with the state stopped, and Play takes the place of this button.

Undo
Press Play to listen again.
HelpOpens this page when you press F1.

Pressing F1 in this window opens the page of the window you are in, in your web browser; the application stays open.

Next
The page opens in your browser. Nothing in the application changes.
Shortcut
F1 works from anywhere in the window.
