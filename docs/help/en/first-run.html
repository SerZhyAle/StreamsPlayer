Where should the channel list come from?

The first time the app starts, its channel list is empty. This window asks where the list should come from, and nothing is downloaded until you choose.

In this order

  1. Choose Import channels from the internet if you are online and want the current list of channels.
  2. Or choose Use the built-in copy to get a ready list at once, without going online. It is as old as this version of the app.
  3. Or choose Start with an empty list to look around first. The list stays empty and nothing is downloaded.

The elements

Import channels from the internetDownloads the current shared channel list and adds it to yours.

Fetches the shared catalog of internet radio and video channels, with the station icons, and adds its channels to your list. It is the same import the Operations menu offers at any later time.

It is the only answer in this window that uses the internet.

Why
The shared list changes as stations come and go, so this gives you the newest one.
Next
The window closes and the download starts. The channels appear in the main window when it finishes.
Undo
An import adds and updates catalog channels only; streams you add yourself or import from a file stay as they are.
Shortcut
Enter chooses it, because it is the button with the focus when the window opens.
Use the built-in copyAdds the channels that came with this version, with no download.

Adds the channel list packed inside this version of the app, together with its icons, and does not go online. The list is as old as the version you installed, so it can miss newer stations.

This answer is shown only when the application contains a built-in copy. If it is missing here, this build has none.

Why
It works with no connection and puts channels in the list at once.
Next
The window closes and the channels appear in the main window. To bring the list up to date later, import channels from the internet in the Operations menu.
Undo
Nothing you made is touched. Channels you do not want can be hidden afterwards.
Start with an empty listStarts with an empty list and downloads nothing.

Closes this window and leaves the channel list empty. You can import channels at any moment from the Operations menu of the main window.

Why
For when you want to look around first, or are offline and do not want the built-in copy yet.
Next
The main window opens with an empty list.
Undo
Nothing changes, so there is nothing to undo.
Shortcut
Esc, or closing the window, does the same.
HelpOpens this page.

Every window that has help carries this button near its top-right corner. It opens the page of the window you are in, in your web browser; the application stays open.

Next
The page opens in your browser. Nothing in the application changes.
Shortcut
F1 does the same from anywhere in the window.
