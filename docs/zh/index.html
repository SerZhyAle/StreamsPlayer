#它是什么，为什么做它

STREAMS Player 是一款独立的 Windows 桌面应用，用于网络广播、直播视频和 RTSP 网络摄像头。它会读取一份公开的精选流目录，因此首次运行就能得到一份可用的频道列表 - 之后您可以搜索、排序、置顶，也可以添加自己的频道，全部保存在您自己的机器上。

它追求的是安静：播放器只做播放器该做的事。目录只在您要求时才更新，您手动添加和导入的流绝不会被更新覆盖，也没有账户、广告、分析统计或作者运营的服务。您的电脑上运行的，只有您自己启动的东西。

#它能做什么

找到、保留并播放一个流所需的一切 - 按您实际在做的事分组。

01找到频道

  • 首次启动即有精选目录 - 无需设置。目录没有给出图标的频道也有自己的样子 - 取自名称的首字母和配色，已知国家/地区时还带上其代码。
  • 按类别、主题、语言、国家/地区和媒体类型筛选 - 需要时再展开该行。
  • 搜索始终位于标题行。
  • 把常回访的频道置顶。
  • 从整份目录中随机播放一个电台 - 若它始终无声，应用会自动换下一个。

02用合适的方式播放

  • 广播在主窗口播放，并在电台提供时显示正在播出的曲目。
  • 停止声音而不丢失电台 - 音量和睡眠定时器仍留在栏上，随时可以继续。
  • 直播视频和 RTSP 在独立的播放器窗口中打开，正在播出的曲目显示在画面之上。
  • 约 15 秒的直播缓冲，视频会稳定在您的网络能承载的画质，下次直接从该画质打开。

03按您的习惯观看

  • 让主窗口或播放器总在最前，或用 F11 进入无边框全屏（Esc 退出）。
  • 播放器是独立窗口 - 最小化目录，画面照常播放。
  • 流图块从超小到大，设置窗口可调整大小，主题可选浅色、深色或跟随 Windows。
  • 把当前画面保存为 JPEG 文件。
  • 画面停住时，播放器会在视频上说明原因 - 并重新打开悄然卡死的流。
  • 电台播放时可把目录缩成一个总在最前的小面板 - 其中有电台、曲目、音量、播放控制和睡眠定时器。

04可视网格

  • 网格会抓取可见的 HTTP(S) 视频预览。
  • 在本地磁盘缓存预览画面，最多 150 MB。
  • 预览的自动更新可以关闭。

05按自己的方式定制

  • 用 URL 添加流，无需账户。
  • 您添加和导入的流不会因目录更新而丢失。您置顶或播放过的目录频道，在目录不再收录它时会被保留，而不是删除。
  • 保留本地的播放标记：成功 / 失败。
  • 整个界面可在十三种语言之间切换，选择会被保留。

06本地优先的设计

  • 目录状态、手动添加的条目和置顶都留在您的设备上。
  • 保存在 %LOCALAPPDATA%\StreamsPlayer。
  • 目录只在您选择时才更新。

#如何使用

打开它，选一个频道 - 整个流程就是这样。可用安装程序，或从 Microsoft Store、winget 或便携版 ZIP 安装，也可以从源代码运行；还可以直接从命令行启动一个流。

  1. 从源代码运行

    装好 .NET 10 SDK 后，在仓库根目录还原、生成并启动。

    ./build.ps1 -Run

  2. 选择并播放

    浏览目录，筛选或搜索，然后选择一个频道。广播在主窗口开始播放；视频和 RTSP 在播放器窗口中打开。普通启动不会播放任何内容；在设置中开启「启动时继续播放」，启动便会恢复上次关闭时正在播放的内容。

  3. 直接打开任意 URL

    不碰目录也能播放一个流。

    StreamsPlayer.exe --url "https://example.test/live"

  4. 把频道保存为快捷方式

    选择一个已保存的频道，打开设置，使用“复制命令”或“创建桌面快捷方式”。两者都使用该频道保存的 id。

    StreamsPlayer.exe --id "channel-guid"

  5. 用日志报告问题

    打开设置，进入“关于”，点击“向作者发送日志”。应用会把本次会话和上一次会话的诊断日志，连同您的版本、Windows 版本和设置的简要说明一起打包到已保存文件文件夹（默认“下载”），然后打开已写好邮件的邮件程序。确认窗口会显示完整路径，并可按您的要求打开该文件夹；由您自己附加压缩包并点击“发送”。
