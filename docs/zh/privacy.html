网络访问

应用程序仅在您执行操作时连接网络，且仅连接至该操作所需的目标：在导入目录或接受图片包时从 GitHub 下载的公共流媒体目录及可选预览包；您播放、录制或查看“关于频道”的流媒体提供商，或在网格模式下刷新预览的提供商；局域网内导入的 FastMediaSorter 手机或手表；以及仅在“设置”的“播放”页面请求时从第三方 GitHub 项目 (BtbN/FFmpeg-Builds) 下载的实验性 FlyleafLib 引擎可选 FFmpeg 库。每个请求均直达目标并受其政策约束；没有任何数据经过作者运行的服务。电视节目单仅在您于“设置”的“资料库”页面输入地址并点击“下载节目单”时下载一次，绝不在后台自动下载。 资料库设置中的可选交换来源通过 TLS 连接到您自己的服务器。注册时仅发送一次登录名和密码或配对码，之后发送设备身份、产品版本、接收能力及设备令牌。启用时保持一个控制连接，发送保活消息并自动重连；禁用后关闭连接。在媒体库设置中导入连接字符串或文件，也可粘贴或拖放到主窗口。它包含服务器地址和可选证书指纹，不含秘密。读取仅填写表单。每次注册输入密码或配对码前请检查地址；两者均不保存。提供的指纹必须匹配，无需信任提示。没有指纹时须在注册前批准服务器指纹；后续证书变更需要批准。无需本地代理或其他程序。 当广播通过您交换服务器的交换服务器并使用固定证书播放时，该流会经过 127.0.0.1 上的一个临时本地代理，该代理仅在广播播放期间存在，且只能从本设备访问。 广播：本应用可以将此电脑的四个来源直播发送 - 您选择的麦克风、电脑正在播放的声音、您选择的一整个显示器和您选择的一个摄像头，其中屏幕和摄像头在同一次广播中各可选择性地携带一路声音（麦克风或系统声音） - 发送到您自己账户的交换服务器或通过您的本地网络，且仅当您在设置中允许并亲自启动每个来源时才会发送；在此之前它是关闭的，关闭时不会采集任何内容，而当某个来源正在直播时，会显示一个带有停止按钮的可见指示器，并显示正在直播的显示器或摄像头的名称。视频为 H.264，最高 1280x720，每秒 30 帧，约 2 Mbit/s，由 Windows 自带的编码器生成；不添加任何组件。所选显示器上的所有内容都会被发送，包括通知和密码，受 Windows 保护的内容可能显示为空白。仅以访客身份登录某服务器的电脑不会广播。听众通过您启用的本地网络或交换服务器连接。您可以限制听众数量。本地网络上的每位听众和每条隧道都会占用此电脑的上传带宽；通过服务器的中继，此电脑只需为所有听众发送一份数据。您交给其他人的广播链接、文件或二维码包含标题、地址和打开广播的密钥，但绝不包含密码。您在设置中选择密码的生成方式：每次广播随机生成（默认）、由您设置（1 到 64 个字符，只保存在您 Windows 账户的 Windows 机密存储中），或无密码，此时任何拿到链接的人都可以观看和收听。广播期间更改会立即使之前的密码失效。实时指示器的“分享”菜单可复制链接、复制密码、将链接显示为供手机扫描的二维码，并保存描述文件。请将链接视为机密，仅与您选择的人分享。账户目录将这些密钥放在加密盒中。 在 64 位查看器中，右键点击视频、音频文件或其文件夹并选择广播。Share Manager 导出 .spres 文件、二维码或快速链接，供 StreamsPlayer 导入。文件夹成为一个包含固定播放列表的频道；刷新会替换列表，撤销会停用链接。HTTP 网关有独立开关，默认关闭。每个令牌只允许读取一个广播，通常在 24 小时后过期。HTTP 未加密：请私下分享文档，仅在需要时启用互联网访问。

交换服务器、广播与加密

交换服务器是私人的：每个人运行自己的服务器，或使用邀请自己加入的服务器。不存在公共交换服务器，任何交换服务器都不是本产品的服务。

交换服务器负责连接您的设备，因此它知道您的账户、设备、文件夹和广播的名称，能看到哪些设备在线，以及传输了多少内容、何时传输。它无法打开经过它的内容：文件夹及其文件、广播和剪贴板都会在您的设备上加密，只能在您的其他设备上或由您授予访问权限的人打开。要查看其中的内容，运营服务器的人必须在您的账户中添加一台自己的设备，而它会出现在您的设备列表中。

登录时，这台电脑只发送一次您的登录名和密码或配对码，然后发送设备标识、设备名称（STREAMS Player，而不是您电脑的名称）、产品、版本和平台（Windows）、角色、接收能力以及其加密密钥的公开部分。连接开启期间，服务器能看到此设备在线。广播时，它会收到广播的标题（屏幕和摄像头的标题会写明显示器或摄像头）、其为音频或视频的信息，以及在这台电脑上加密后才离开的音频或视频本身；私钥永远不会离开这台电脑。

广播可以发送这台电脑的四个来源：您选择的麦克风、电脑正在播放的声音、您选择的一整个显示器和您选择的一个摄像头；屏幕和摄像头在同一次广播中各可携带一路声音，即麦克风或系统声音。视频为 H.264，最高 1280x720，每秒 30 帧，约 2 Mbit/s，由 Windows 自带的编码器生成；不添加任何组件。在您于设置中允许之前它保持关闭，关闭期间不采集任何内容，每个来源都由您自己启动；来源在线期间会显示带停止按钮的醒目指示，并显示正在直播的显示器或摄像头的名称。所选显示器上的所有内容都会被发送，包括通知和密码，受 Windows 保护的内容可能显示为空白。仅以访客身份登录某服务器的电脑不会广播。本地网络上的每位听众和每条隧道都会占用这台电脑的上传带宽；通过服务器的中继，这台电脑只需为所有听众发送一份数据。您交给账户之外的人的链接、文件和二维码绝不包含密码。密码如何生成由您选择：每次广播随机生成（默认）、由您设置（1 到 64 个字符，只保存在您 Windows 账户的 Windows 机密存储中），或无密码，此时任何拿到链接的人都可以观看和收听。广播期间更改会立即使之前的密码失效。实时指示器的“分享”菜单可复制链接和密码、将链接显示为供手机扫描的二维码，并保存描述文件。 只有当您另外开启随应用程序启动的选项时，您保留所选的来源才会在应用程序启动、账户上线后再次启动。听众的设备可以录制其收到的内容，本程序无法阻止。

此电脑的摄像头有两种用途，每种都只做一件事。第一种：当你在设置中点击“用摄像头扫描”时读取连接二维码。扫描窗口打开期间，画面只在内存中查看以找到二维码，绝不会被保存、发送或记入日志；窗口一关闭，摄像头即被释放。如果 Windows 未报告摄像头，则不会提供该按钮。第二种：把你选择的摄像头的画面作为广播发送，且仅当你自己在设置中用“广播摄像头”启动时：画面随后在此电脑上编码，并作为该广播发送；广播停止时，摄像头即被释放。

本程序只登录，从不创建账户。账户在手机上的 FastMediaSorter 中删除，或请运行该服务器的人删除；交换门户说明了方法。在此设备上退出登录只会移除此设备，而不是账户。

Google 登录为可选功能，仅请求 drive.appdata 权限。Google 通过 accounts.google.com、oauth2.googleapis.com 和 www.googleapis.com 接收登录及 API 请求。仅读取隐藏应用数据中的设备名称（fmsx-device-*）和广播公告（fmsx-broadcast-*）。此电脑在广播期间写入和更新自己的公告，并在结束时删除；媒体从不通过 Drive 传输。仅在列表窗口打开且未最小化时轮询目录。刷新令牌受当前 Windows 用户保护。退出会删除令牌并请求 Google 撤销访问；撤销失败会明确提示。公告保存在您的 Google 账号中，不额外进行端到端加密。

如何删除账户

本网站

本节说明的是网站，而不是应用程序。每个页面都从 Google Fonts 加载字体：浏览器向 fonts.googleapis.com 请求样式表，向 fonts.gstatic.com 请求字体文件，因此 Google 会收到您的 IP 地址、浏览器信息以及您正在阅读的页面地址。主页还会向 api.github.com 查询一次最新版本，使安装程序按钮指向当前文件；GitHub 会收到您的 IP 地址和浏览器信息。页面本身由 GitHub Pages（serzhyale.github.io）提供。本网站没有统计分析、广告或跟踪，不设置 cookie，只在浏览器本地存储中保存您选择的主题和语言。上述每项服务都适用其各自的政策，均不由作者运营。

本地数据

STREAMS Player 将目录状态、添加和导入的频道、固定项、合集、隐藏频道、收听历史、播放标记、150 MB 预算内的缓存预览帧、可选 FFmpeg 库以及最近十次启动的诊断日志存储在 %LOCALAPPDATA%\StreamsPlayer 下。录制和保存的帧存储在您选择的文件夹中（默认为 Videos/Recordings、Music/Recordings 和 Pictures/Frames）。除非您在“设置”的“关于”页面使用“向作者发送日志”将其发送至 sza@ukr.net，否则这些数据始终保留在您的设备上。下载的电视节目单及其频道绑定也保存在该处；在“设置”中点击“移除节目单”将同时删除两者。 密码和配对码随后清除。账户、令牌及证书指纹保存在单独文件中，仅供当前 Windows 用户解密；移除账户后清除这些内容。诊断压缩包不包含此文件，并隐藏账户信息。只有您明确设置此来源后才会连接交换服务器。 此设备保存一个交换账户。更换服务器或登录名时，会先确认移除当前账户；重新登录同一账户会保留设备身份。移除账户时，应用会请求服务器移除此设备，然后清除本地连接，即使服务器不可用也会完成。已导入的频道会保留。如果无法通知服务器，应用会提示此设备可能仍在列表中，直到其他设备将其移除；不会在后台重试移除。
