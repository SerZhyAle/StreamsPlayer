STREAMS Player · 隐私

默认保护隐私。

普通播放无需账户。可选的交换账户属于您自己的服务器。没有广告、分析、遥测或作者运营的服务。

网络访问

应用程序仅在您执行操作时连接网络，且仅连接至该操作所需的目标：在导入目录或接受图片包时从 GitHub 下载的公共流媒体目录及可选预览包；您播放、录制或查看“关于频道”的流媒体提供商，或在网格模式下刷新预览的提供商；局域网内导入的 FastMediaSorter 手机或手表；以及仅在“设置”的“播放”页面请求时从第三方 GitHub 项目 (BtbN/FFmpeg-Builds) 下载的实验性 FlyleafLib 引擎可选 FFmpeg 库。每个请求均直达目标并受其政策约束；没有任何数据经过作者运行的服务。电视节目单仅在您于“设置”的“资料库”页面输入地址并点击“下载节目单”时下载一次，绝不在后台自动下载。 资料库设置中的可选交换来源通过 TLS 连接到您自己的服务器。注册时仅发送一次登录名和密码或配对码，之后发送设备身份、产品版本、接收能力及设备令牌。启用时保持一个控制连接，发送保活消息并自动重连；禁用后关闭连接。每张服务器证书都需您明确批准，包括续期后。 当广播通过您交换服务器的中继并使用固定证书播放时，该流会经过 127.0.0.1 上的一个临时本地代理，该代理仅在广播播放期间存在，且只能从本设备访问。

本网站

本节说明的是网站，而不是应用程序。每个页面都从 Google Fonts 加载字体：浏览器向 fonts.googleapis.com 请求样式表，向 fonts.gstatic.com 请求字体文件，因此 Google 会收到您的 IP 地址、浏览器信息以及您正在阅读的页面地址。主页还会向 api.github.com 查询一次最新版本，使安装程序按钮指向当前文件；GitHub 会收到您的 IP 地址和浏览器信息。页面本身由 GitHub Pages（serzhyale.github.io）提供。本网站没有统计分析、广告或跟踪，不设置 cookie，只在浏览器本地存储中保存您选择的主题和语言。上述每项服务都适用其各自的政策，均不由作者运营。

本地数据

STREAMS Player 将目录状态、添加和导入的频道、固定项、合集、隐藏频道、收听历史、播放标记、150 MB 预算内的缓存预览帧、可选 FFmpeg 库以及最近十次启动的诊断日志存储在 %LOCALAPPDATA%\StreamsPlayer 下。录制和保存的帧存储在您选择的文件夹中（默认为 Videos/Recordings、Music/Recordings 和 Pictures/Frames）。除非您在“设置”的“关于”页面使用“向作者发送日志”将其发送至 serzhyale@gmail.com，否则这些数据始终保留在您的设备上。下载的电视节目单及其频道绑定也保存在该处；在“设置”中点击“移除节目单”将同时删除两者。 密码和配对码随后清除。账户、令牌及证书指纹保存在单独文件中，仅供当前 Windows 用户解密；移除账户后清除这些内容。诊断压缩包不包含此文件，并隐藏账户信息。只有您明确设置此来源后才会连接交换服务器。
