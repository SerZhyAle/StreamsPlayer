STREAMS Player · 安装

Windows 发出了警告。这是它的含义。

STREAMS Player 是一位独立开发者制作的免费应用。如果您第一次打开下载的文件时被 Windows 拦下，本页会说明那个界面是什么、为什么会出现、具体该点哪里，以及这款应用绝不会做的事。读完大约只需三十秒。

“Windows 已保护你的电脑”

这个界面是 Microsoft Defender SmartScreen（在英文版 Windows 上，标题为“Windows protected your PC”）。标题下方写着它“阻止了无法识别的应用启动”，点击“更多信息”后，发布者显示为“未知发布者”。当您打开一个从互联网下载、没有数字签名、而且 Windows 还没有在许多电脑上见过其运行的文件时，就会出现这个界面。

这是针对一个 Windows 还不认识的文件的提醒，而不是说在文件里发现了什么 - 这也是 Windows 在尽职：它无法判断一个未签名的文件是谁制作的，所以在运行之前先问您。

为什么这款应用会出现这个界面

STREAMS Player 的安装程序、便携版 ZIP 和 winget 软件包都没有代码签名。代码签名证书每年要花费数百美元，对于一款没有任何收入的免费应用，我们目前选择不购买。这是一个决定，而不是疏忽 - 对于未签名的文件，发出警告正是 Windows 应该做的。

SmartScreen 还会参考信誉：运行同一个文件且没有出问题的人越多，Windows 就越早认出它，警告也就不再出现。每次发布都是一个从零开始的新文件，所以更新之后警告可能再次出现，并会随着该版本被更多人使用而逐渐消失。

Microsoft Store 版本由 Microsoft 签名，不会显示这个界面。每次 GitHub 发布也会在每个下载文件旁附上一个 .sha256 文件：在 PowerShell 中对您下载的文件运行 Get-FileHash -Algorithm SHA256 <file>，结果应与该文件中的值一致。

该点哪里

在“Windows 已保护你的电脑”界面上：

  1. 点击消息下方的“更多信息”（More info）。
  2. 确认文件名是您下载的 STREAMS Player 文件，然后点击“仍要运行”（Run anyway）。

就这些 - 安装程序，或 ZIP 中的应用，会正常启动。您永远不需要关闭 SmartScreen 或禁用杀毒软件，应用本身也从不需要管理员权限。

“你要允许来自未知发布者的此应用对你的设备进行更改吗？”

通常您不会看到这个提示。安装程序默认只为您一人安装到 %LOCALAPPDATA%\Programs\StreamsPlayer，为此不需要管理员权限。如果它询问安装方式，请选择“Install for me only (recommended)”（仅为我安装，推荐）。

只有当您选择“Install for all users”（为所有用户安装）时，Windows 才会显示这个提示。此时安装程序只把管理员权限用于以下三件事：

  • 把程序复制到 Program Files 文件夹，让这台电脑上的每个账户都能运行它；
  • 把 STREAMS Player 添加到每个账户的“开始”菜单，如果您勾选了相应选项，还会添加到公用桌面；
  • 在 Windows 中把它登记为已安装的应用，以便日后可以卸载。

一个操作就能同时撤销这三项：设置 > 应用 > 已安装的应用（Windows 10 上为“应用和功能”）> STREAMS Player > 卸载。如果您不想授予管理员权限，请点击“否”（No），然后重新运行安装程序并选择“Install for me only”（仅为我安装）。

如果杀毒软件拦下了文件

有些杀毒软件对新的、未签名的文件比较谨慎。如果您的杀毒软件隔离了 STREAMS Player，请把它恢复，并只为它所在的文件夹添加例外 - 安装程序版为 %LOCALAPPDATA%\Programs\StreamsPlayer，ZIP 版则是您解压到的文件夹。只需为这一个文件夹添加例外即可，您随时可以删除它；不要关闭杀毒软件。

STREAMS Player 绝不会做的事

  • 它安装和运行都从不需要管理员权限，从不把自己加入 Windows 启动项，也不安装任何后台服务。
  • 普通播放无需账户。可选的交换账户属于您自己的服务器。没有广告、分析、遥测或作者运营的服务。
  • 它仅在您操作时连接网络，且仅用于该操作所需的内容：GitHub 上的公共流媒体目录及预览包、所播放/录制/预览的流媒体提供商、局域网内的 FastMediaSorter 设备以及在“设置”中请求的可选 FFmpeg 库。电视节目单仅在您点击“下载节目单”时从您自行输入的地址获取。
  • 它从不自行下载目录 - 只有在您要求时才会更新。
  • 它绝不会自动发送您的数据或日志。“设置”中“关于”页面的“向作者发送日志”仅在您的邮件客户端中准备归档和邮件；在您自行点击发送前，任何内容都不会离开您的设备。
  • 卸载它从不会删除您的频道、置顶或播放记录 - 它们会留在 %LOCALAPPDATA%\StreamsPlayer，直到您自己删除该文件夹。
