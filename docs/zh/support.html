STREAMS Player 由一位独立开发者制作。本页说明报告里应写什么、发到哪里，以及您可以期待什么样的回复。

报告问题

在 GitHub 上提交一个 issue。表单会询问发生了什么、导致问题的步骤、STREAMS Player 的版本和 Windows 的版本。应用版本可在“设置”窗口的“关于”页面中找到。如果问题涉及某个具体频道，请写出它的名称。提交 issue 需要一个免费的 GitHub 账户；如果您没有，请使用本页下方的地址。

用日志报告问题

从标题行中的齿轮按钮，或从 “操作”菜单的“媒体库设置”项打开“设置”，并在“关于”页面点击“向作者发送日志”。应用会将最近十次启动的诊断日志以及版本、Windows 和设置摘要打包到您在“设置”的“文件”页面中为“画面文件夹”选定的文件夹；若尚未选定，则打包到“下载”文件夹，然后打开已准备好邮件的邮件客户端。确认信息会显示完整路径并可按您的要求打开该文件夹；由您自行添加附件并点击发送。

某个频道停止播放

目录是一份公开的流列表，这些流由其他人运营：电台、广播机构、摄像头所有者。STREAMS Player 把它们的地址保存在您的设备上，并且如隐私页面所述，只在您操作时才连接网络；流本身仍由运营者掌握，因此一个流可能迁移、更改格式、只在另一个地区可用，或永久停播，目录也会随时间变化。频道出错时，“流不可用”窗口可能会视具体故障提供“重试”“复制报告”“隐藏”（对于您自己添加或导入的频道则是“删除”）和“保留”。具体出现哪些取决于故障：对于应用完全无法播放的地址，不会出现“重试”；没有网络连接时，不会出现“隐藏”或“删除”，因为此时并未连上该频道。“重试”会再试一次，您也可以直接打开另一个频道；“隐藏”会把该频道从您的列表中移除，您可以把它找回来：在“设置”的“媒体库”页面中点击“已隐藏”，再点击该频道旁边的“取消隐藏”；“复制报告”会把一段简短的说明放到剪贴板，供您粘贴到 issue 中，应用本身不会发送任何内容。“操作”菜单中的“从互联网导入频道”会下载当前的目录，而且只在您要求时才下载。流消失并不是应用的故障，也不承诺会修复。

Windows 发出了警告

如果 Windows 用“Windows 已保护你的电脑”界面拦下了安装程序，那是 Microsoft Defender SmartScreen 对它尚不认识的文件做出的反应，并不是在文件里发现了什么的报告。“安装帮助”页面说明了这个界面的含义以及具体该点哪里。
