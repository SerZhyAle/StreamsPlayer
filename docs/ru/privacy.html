Трансляции · Конфиденциальность

Приватность по умолчанию.

Для обычного воспроизведения аккаунт не требуется. Необязательный аккаунт обмена принадлежит вашему серверу. Нет рекламы, аналитики, телеметрии или сервиса, управляемого автором.

Доступ к сети

Приложение подключается к сети только по вашему действию и только туда, куда необходимо для этого действия: к общедоступному каталогу трансляций и предлагаемому вслед за ним набору картинок предпросмотра, скачиваемым с GitHub при импорте каталога или принятии набора; к источнику трансляции, которую вы воспроизводите, записываете или для которой открываете карточку «О канале», либо чей видеокадр обновляется в режиме сетки; к телефону или часам FastMediaSorter, которые вы импортировали, напрямую в вашей локальной сети; и, только если вы запросите их в «Настройках» на вкладке «Воспроизведение», к необязательным библиотекам FFmpeg для экспериментального движка FlyleafLib, скачиваемым из стороннего проекта на GitHub (BtbN/FFmpeg-Builds). Каждый запрос идёт напрямую к месту назначения и подчиняется его правилам; ни один запрос не проходит через службы автора приложения. Телепрограмма скачивается только по адресу, который вы сами ввели в «Настройках» на вкладке «Библиотека», один раз при каждом нажатии «Скачать программу», и никогда в фоновом режиме. Необязательный источник обмена в настройках библиотеки подключается к вашему серверу по TLS. При регистрации отправляются логин и пароль или код сопряжения, затем идентификатор устройства, версия продукта, возможности приёмника и токен. Пока источник включён, сохраняется одно соединение с проверками активности и повторным подключением; выключение закрывает его. Каждый сертификат требует явного подтверждения, в том числе после обновления. Когда трансляция идёт через ретранслятор вашего сервера обмена с закреплённым сертификатом, этот один поток проходит через временный локальный прокси на 127.0.0.1, который существует только пока трансляция воспроизводится и доступен только с этого устройства.

Этот сайт

Этот раздел - о сайте, а не о приложении. Каждая страница загружает шрифты из Google Fonts: браузер запрашивает таблицу стилей у fonts.googleapis.com и файлы шрифтов у fonts.gstatic.com, поэтому Google получает ваш IP-адрес, сведения о браузере и адрес читаемой страницы. Главная страница также один раз обращается к api.github.com за последним выпуском, чтобы кнопка установщика вела на актуальный файл; GitHub получает ваш IP-адрес и сведения о браузере. Сами страницы отдаёт GitHub Pages (serzhyale.github.io). На сайте нет аналитики, рекламы и слежения, он не устанавливает cookie и хранит в локальном хранилище браузера только выбор темы и языка. Каждый из этих сервисов подчиняется собственной политике; ни один не управляется автором.

Локальные данные

Трансляции хранит состояние каталога, добавленные и импортированные вами каналы, закрепления, подборки, скрытые каналы, историю прослушивания, отметки воспроизведения, кадры предпросмотра в пределах 150 МБ, необязательные библиотеки FFmpeg, если вы их скачали, и журналы диагностики десяти последних запусков в %LOCALAPPDATA%\StreamsPlayer. Записи и сохранённые кадры попадают в выбранные вами папки, а по умолчанию - в Recordings в «Видео», Recordings в «Музыке» и Frames в «Изображениях». Эти данные остаются на устройстве, пока вы сами не скопируете или не сохраните их резервную копию - либо пока вы не воспользуетесь кнопкой «Отправить журналы автору» в «Настройках» на вкладке «О программе», которая упаковывает эти журналы диагностики вместе с версией приложения, версией Windows и настройками в архив и открывает вашу почтовую программу, чтобы вы прикрепили его и отправили на sza@ukr.net. Архив создаётся только по нажатию этой кнопки, в журналах названы потоки, которые воспроизводились, и ничего не отправляется без того, чтобы вы сами нажали «Отправить» в своей почтовой программе. Там же хранятся загруженная телепрограмма и выбранные вами каналы программы; «Удалить программу» в «Настройках» удаляет и то и другое. Пароль и код удаляются из памяти. Аккаунт, токен и отпечаток защищены для вашего пользователя Windows в отдельном файле; удаление аккаунта забывает их. Архив диагностики не включает этот файл и скрывает данные аккаунта. Соединение начинается только после вашей явной настройки источника.
