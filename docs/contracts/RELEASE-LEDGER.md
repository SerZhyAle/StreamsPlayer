1. **Declare packages and public channel identities:** `docs/releases/channels.json` carries `schema` `"1"`, one package `app` (`StreamsPlayer`), and every channel listed in `.sza-canon.json` (`github`: `SerZhyAle/StreamsPlayer`, `winget`: `SerZhyAle.StreamsPlayer`, `msstore`: `9NBTD5SXB8TB`).
2. **Record every build without failing the build:** `build.ps1`, `tools/build-installer.ps1`, and `msix/build-msix.ps1` invoke `scripts/Invoke-ReleaseLedger.ps1 -Verb build -BestEffort` as their last step so `builds.json` holds the last build per package, flavor, and kind while ledger errors warn and leave the build exit code untouched.
3. **Record release channel steps and keep `RELEASES.md` rendered:** `scripts/release.ps1` records each channel step (`publish`) and verifies live state (`probe`, `show`); `docs/releases/RELEASES.md` is a render target regenerated by the writer and never hand-edited.
4. **Keep secrets and local machine facts out of the ledger:** no credential, token, seller/tenant/client id, or absolute local path enters `docs/releases/`.
