STREAMS Player · Support

Etwas funktioniert nicht? So melden Sie es.

STREAMS Player wird von einem unabhängigen Entwickler gemacht. Diese Seite sagt, was in eine Meldung gehört, wohin Sie sie schicken und was Sie als Antwort erwarten können.

Einen Fehler melden

Erstellen Sie auf GitHub ein Issue. Das Formular fragt, was passiert ist, welche Schritte dorthin geführt haben, welche Version von STREAMS Player Sie nutzen und welche Windows-Version. Die App-Version finden Sie auf der Seite «Über» im Fenster Einstellungen. Ist ein bestimmter Kanal betroffen, nennen Sie ihn. Für ein Issue brauchen Sie ein kostenloses GitHub-Konto; haben Sie keines, nutzen Sie die Adresse weiter unten auf dieser Seite.

Auf GitHub melden

Ein Problem mithilfe der Protokolle melden

Öffnen Sie die Einstellungen über die Zahnrad-Schaltfläche in der Kopfzeile (oder über den Eintrag «Bibliothekseinstellungen» im Menü «Aktionen») und drücken Sie auf der Seite «Über» auf «Protokolle an den Autor senden». Die App packt die Diagnoseprotokolle der letzten zehn Starts mit einer kurzen Zusammenfassung Ihrer Version, Windows und Einstellungen in den Ordner, der auf der Seite «Dateien» der Einstellungen unter «Ordner für Bilder» festgelegt ist (ist keiner festgelegt, Downloads), und öffnet dann Ihr E-Mail-Programm mit der vorbereiteten Nachricht. Die Bestätigung zeigt den vollständigen Pfad und kann diesen Ordner auf Wunsch öffnen; Sie hängen das Archiv an und drücken selbst auf Senden.

Ein Kanal spielt nicht mehr

Der Katalog ist eine öffentliche Liste von Streams, die andere betreiben: Radiosender, Rundfunkveranstalter, Kamerabesitzer. STREAMS Player behält deren Adressen auf Ihrem Gerät und verbindet sich, wie die Datenschutzseite erklärt, nur dann mit dem Netzwerk, wenn Sie etwas tun; die Streams selbst bleiben bei denen, die sie betreiben, daher kann ein Stream umziehen, das Format wechseln, nur noch in einer anderen Region verfügbar sein oder für immer abgeschaltet werden, und der Katalog ändert sich mit der Zeit. Fällt ein Kanal aus, kann das Fenster «Stream nicht verfügbar» «Wiederholen», «Bericht kopieren», «Ausblenden» («Löschen» bei einem Kanal, den Sie selbst hinzugefügt oder importiert haben) und «Behalten» anbieten. Welche davon erscheinen, hängt vom Fehler ab: «Wiederholen» entfällt bei einer Adresse, die die App gar nicht abspielen kann, und «Ausblenden» oder «Löschen» entfällt, wenn keine Netzwerkverbindung besteht, weil der Kanal dann nie erreicht wurde. «Wiederholen» versucht es erneut, oder Sie öffnen einfach einen anderen Kanal; «Ausblenden» nimmt den Kanal aus Ihrer Liste, und Sie können ihn zurückholen: Drücken Sie in den Einstellungen auf der Seite «Bibliothek» auf «Ausgeblendet» und dann neben dem Kanal auf «Einblenden»; «Bericht kopieren» legt eine kurze Notiz in die Zwischenablage, die Sie in ein Issue einfügen können, und die App sendet nichts. «Kanäle aus dem Internet importieren» im Menü «Aktionen» lädt den aktuellen Katalog herunter, und nur, wenn Sie es verlangen. Ein Stream, den es nicht mehr gibt, ist kein Fehler der App, und eine Behebung wird nicht versprochen.

Windows hat gewarnt

Wenn Windows das Installationsprogramm mit dem Bildschirm „Der Computer wurde durch Windows geschützt“ angehalten hat, reagiert Microsoft Defender SmartScreen auf eine Datei, die es noch nicht kennt. Das ist keine Meldung über etwas, das in der Datei gefunden wurde. Die Seite zur Installationshilfe erklärt, was dieser Bildschirm bedeutet und worauf Sie genau klicken.

Direkt an den Autor schreiben

Wenn Sie GitHub lieber nicht nutzen möchten oder die Angelegenheit nicht öffentlich sein soll, schreiben Sie an sza@ukr.net. Sicherheitsmeldungen gehören hierher und nicht in ein öffentliches Issue. Das gilt auch für Diagnoseprotokolle, in denen die von Ihnen abgespielten Streams stehen.

Was Sie erwarten können

Dies ist ein unabhängiges Projekt. Der Autor antwortet, wenn es die Zeit erlaubt; eine Antwortzeit wird nicht versprochen, ebenso wenig eine Behebung für jede Meldung. Eine Meldung, die Version, Schritte und Kanal nennt, lässt sich leichter bearbeiten.
