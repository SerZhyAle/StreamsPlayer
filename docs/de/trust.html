STREAMS Player · Installation

Windows hat Sie gewarnt. Das bedeutet es.

STREAMS Player ist eine kostenlose App eines unabhängigen Entwicklers. Wenn Windows sie beim ersten Öffnen des Downloads angehalten hat, erklärt diese Seite, was dieser Bildschirm ist, warum er erscheint, worauf Sie genau klicken und was die App nie tut. Das Lesen dauert etwa dreißig Sekunden.

„Der Computer wurde durch Windows geschützt“

Dieser Bildschirm ist Microsoft Defender SmartScreen (auf einem englischen Windows lautet die Überschrift „Windows protected your PC“). Unter der Überschrift steht, dass der „Start einer unbekannten App verhindert“ wurde, und nach „Weitere Informationen“ nennt er als Herausgeber „Unbekannter Herausgeber“. Er erscheint, wenn Sie eine aus dem Internet heruntergeladene Datei öffnen, die nicht digital signiert ist und die Windows noch nicht auf vielen PCs hat laufen sehen.

Es ist ein Hinweis zur Vorsicht bei einer Datei, die Windows noch nicht kennt, keine Meldung über etwas, das darin gefunden wurde - und Windows tut damit seine Arbeit: Es kann nicht erkennen, wer eine nicht signierte Datei erstellt hat, und fragt Sie deshalb, bevor es sie ausführt.

Warum er bei dieser App erscheint

Das Installationsprogramm, das portable ZIP und das winget-Paket von STREAMS Player sind nicht codesigniert. Ein Codesignaturzertifikat kostet Hunderte Dollar im Jahr, und für eine kostenlose App ohne Einnahmen haben wir uns vorerst entschieden, keines zu kaufen. Das ist eine Entscheidung, kein Versehen - und bei einer nicht signierten Datei ist eine Warnung genau das, was Windows zeigen sollte.

SmartScreen berücksichtigt außerdem die Reputation: Je mehr Menschen dieselbe Datei ohne Probleme ausführen, desto eher erkennt Windows sie, und die Warnung bleibt aus. Jedes Release ist eine neue Datei, die bei null beginnt - deshalb kann die Warnung nach einem Update wiederkommen, und deshalb lässt sie nach, je mehr ein Release genutzt wird.

Die Version aus dem Microsoft Store ist von Microsoft signiert und zeigt diesen Bildschirm nicht. Zu jedem Release auf GitHub erscheint außerdem neben jedem Download eine .sha256-Datei: Führen Sie Get-FileHash -Algorithm SHA256 <file> in PowerShell für die heruntergeladene Datei aus - das Ergebnis sollte mit dem Wert in dieser Datei übereinstimmen.

Worauf Sie klicken

Auf dem Bildschirm „Der Computer wurde durch Windows geschützt“:

  1. Klicken Sie unter der Meldung auf „Weitere Informationen“ (More info).
  2. Prüfen Sie, dass der Dateiname der von Ihnen heruntergeladenen Datei von STREAMS Player entspricht, und klicken Sie dann auf „Trotzdem ausführen“ (Run anyway).

Das ist alles - das Installationsprogramm oder die App aus dem ZIP startet ganz normal. Sie müssen SmartScreen nie ausschalten und Ihr Antivirenprogramm nie deaktivieren, und die App selbst braucht nie Administratorrechte.

„Möchten Sie zulassen, dass durch diese App von einem unbekannten Herausgeber Änderungen an Ihrem Gerät vorgenommen werden?“

Diese Abfrage sollten Sie normalerweise nicht sehen. Standardmäßig installiert das Installationsprogramm nur für Sie, nach %LOCALAPPDATA%\Programs\StreamsPlayer, und braucht dafür keine Administratorrechte. Fragt es, wie installiert werden soll, wählen Sie „Installation nur für Sie (empfohlen)“.

Windows zeigt diese Abfrage nur, wenn Sie „Installation für alle Benutzer“ wählen. Das Installationsprogramm nutzt die Administratorrechte dann für genau drei Dinge:

  • das Programm in den Ordner „Programme“ (Program Files) zu kopieren, damit jedes Konto auf diesem PC es starten kann;
  • STREAMS Player dem Startmenü jedes Kontos hinzuzufügen und dem gemeinsamen Desktop, falls Sie diese Option angehakt haben;
  • es bei Windows als installierte App zu registrieren, damit es später entfernt werden kann.

Ein einziger Schritt entfernt alle drei zusammen: Einstellungen > Apps > Installierte Apps (unter Windows 10 Apps & Features) > STREAMS Player > Deinstallieren. Wenn Sie lieber keine Administratorrechte vergeben möchten, klicken Sie auf „Nein“ und starten Sie das Installationsprogramm erneut mit „Installation nur für Sie“.

Wenn Ihr Antivirenprogramm die Datei zurückhält

Manche Antivirenprogramme sind bei neuen, nicht signierten Dateien vorsichtig. Stellt Ihres STREAMS Player unter Quarantäne, stellen Sie die Datei wieder her und fügen Sie eine Ausnahme nur für ihren Ordner hinzu - %LOCALAPPDATA%\Programs\StreamsPlayer beim Installationsprogramm oder den Ordner, in den Sie das ZIP entpackt haben. Eine Ausnahme für diesen einen Ordner genügt, und Sie können sie jederzeit wieder entfernen; schalten Sie Ihr Antivirenprogramm nicht aus.

Was STREAMS Player nie tut

  • Die App braucht nie Administratorrechte, um installiert zu werden oder zu laufen, trägt sich nie in den Windows-Autostart ein und installiert keinen Hintergrunddienst.
  • Für die normale Wiedergabe ist kein Konto erforderlich. Das optionale Austauschkonto gehört zu Ihrem eigenen Server. Es gibt keine Werbung, Analyse, Telemetrie oder vom Autor betriebenen Dienste.
  • Sie stellt nur dann eine Verbindung her, wenn Sie handeln, und nur für das, was diese Aktion erfordert: den öffentlichen Stream-Katalog und das optionale Vorschau-Paket auf GitHub, den Anbieter eines Streams, den Sie abspielen, aufnehmen oder in der Vorschau anzeigen, ein FastMediaSorter-Gerät in Ihrem Netzwerk und die optionalen FFmpeg-Bibliotheken, wenn Sie diese in den Einstellungen anfordern. Ein TV-Programm wird nur von einer von Ihnen selbst eingegebenen Adresse abgerufen, wenn Sie auf «Programm herunterladen» drücken.
  • Sie lädt den Katalog nie von sich aus herunter - eine Aktualisierung geschieht nur, wenn Sie sie verlangen.
  • Sie sendet niemals selbst Daten oder Protokolle. «Protokolle an den Autor senden» auf der Seite «Über» in den Einstellungen bereitet lediglich ein Archiv und eine E-Mail in Ihrem E-Mail-Programm vor; nichts verlässt Ihr Gerät, bis Sie dort auf Senden drücken.
  • Beim Deinstallieren werden Ihre Kanäle, Anheftungen und Ihr Verlauf nie gelöscht - sie bleiben in %LOCALAPPDATA%\StreamsPlayer, bis Sie diesen Ordner selbst entfernen.
