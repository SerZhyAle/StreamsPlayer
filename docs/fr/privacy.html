STREAMS Player · Confidentialité

Privé par défaut.

Aucun compte n’est requis pour la lecture habituelle. Le compte d’échange facultatif appartient à votre propre serveur. Il n’y a ni publicité, ni analyse d’usage, ni télémétrie, ni service géré par l’auteur.

Accès au réseau

L’application ne se connecte que lors de vos actions et uniquement vers les destinations nécessaires : le catalogue public de flux et le pack d’aperçus facultatif sur GitHub lors de l’importation ; le fournisseur d’un flux que vous lisez, enregistrez ou consultez dans « À propos de la chaîne », ou dont l’aperçu s’actualise en mode grille ; un appareil FastMediaSorter sur votre réseau local ; et, uniquement si vous les demandez dans Paramètres sur la page Lecture, les bibliothèques FFmpeg facultatives pour le moteur expérimental FlyleafLib (BtbN/FFmpeg-Builds). Chaque requête va directement à destination ; aucun intermédiaire n’est géré par l’auteur. Le programme TV est téléchargé uniquement depuis l’adresse saisie dans Paramètres sur la page Bibliothèque, une seule fois lors du clic sur « Télécharger le programme », et jamais en arrière-plan. La source d’échange facultative dans les paramètres de bibliothèque se connecte à votre serveur par TLS. Elle envoie l’identifiant et le mot de passe ou le code d’association une fois pour l’inscription, puis l’identité de l’appareil, la version du produit, ses capacités de réception et son jeton. Elle maintient une connexion de contrôle avec messages de présence et reconnexions tant qu’elle est activée ; la désactiver ferme la connexion. Chaque certificat exige votre accord explicite, y compris après renouvellement.

Ce site web

Cette section concerne le site web, pas l'application. Chaque page charge ses polices depuis Google Fonts : votre navigateur demande une feuille de style à fonts.googleapis.com et les fichiers de police à fonts.gstatic.com, de sorte que Google reçoit votre adresse IP, les informations de votre navigateur et l'adresse de la page que vous lisez. La page d'accueil interroge aussi une fois api.github.com pour connaître la dernière version, afin que le bouton d'installation pointe vers le fichier actuel ; GitHub reçoit votre adresse IP et les informations de votre navigateur. Les pages elles-mêmes sont servies par GitHub Pages (serzhyale.github.io). Le site n'utilise ni statistiques, ni publicité, ni suivi, ne dépose aucun cookie et ne conserve dans le stockage local de votre navigateur que votre choix de thème et de langue. Chacun de ces services est soumis à sa propre politique ; aucun n'est exploité par l'auteur.

Données locales

STREAMS Player stocke l’état du catalogue, vos chaînes ajoutées et importées, épingles, collections, chaînes masquées, historique d’écoute, repères de lecture, aperçus mis en cache dans une limite de 150 Mo, les bibliothèques FFmpeg facultatives et les journaux de diagnostic des dix derniers lancements sous %LOCALAPPDATA%\StreamsPlayer. Les enregistrements et captures vont dans les dossiers choisis (par défaut Videos/Recordings, Music/Recordings et Pictures/Frames). Ces données restent sur votre appareil sauf si vous utilisez « Envoyer les journaux à l’auteur » dans Paramètres sur la page À propos pour les transmettre à serzhyale@gmail.com. Le programme TV téléchargé et vos correspondances y sont aussi conservés ; « Supprimer le programme » dans Paramètres supprime les deux. Le mot de passe et le code sont supprimés. Le compte, le jeton et l’empreinte sont protégés pour votre utilisateur Windows dans un fichier séparé ; supprimer le compte les efface. Les archives de diagnostic excluent ce fichier et masquent les valeurs du compte. Les connexions d’échange commencent seulement après votre configuration explicite de la source.
