STREAMS Player · Installation

Windows vous a averti. Voici ce que cela signifie.

STREAMS Player est une application gratuite d'un développeur indépendant. Si Windows l'a arrêtée la première fois que vous avez ouvert le téléchargement, cette page explique ce qu'est cet écran, pourquoi il apparaît, sur quoi cliquer exactement et ce que l'application ne fait jamais. Sa lecture prend environ trente secondes.

« Windows a protégé votre ordinateur »

Cet écran, c'est Microsoft Defender SmartScreen (sur un Windows en anglais, le titre est « Windows protected your PC »). Sous le titre, il indique avoir « empêché le démarrage d'une application non reconnue », et après « Informations complémentaires », il désigne l'éditeur comme « Éditeur inconnu ». Il apparaît quand vous ouvrez un fichier téléchargé depuis Internet qui n'est pas signé numériquement et que Windows n'a pas encore vu s'exécuter sur beaucoup de PC.

C'est une mise en garde à propos d'un fichier que Windows ne connaît pas encore, pas le signalement de quelque chose trouvé à l'intérieur - et c'est Windows qui fait son travail : il ne peut pas savoir qui a créé un fichier non signé, alors il vous demande votre accord avant de l'exécuter.

Pourquoi il apparaît pour cette application

Le programme d'installation, le ZIP portable et le paquet winget de STREAMS Player ne sont pas signés numériquement. Un certificat de signature de code coûte des centaines de dollars par an, et pour une application gratuite sans revenus, nous avons choisi de ne pas en acheter pour l'instant. C'est une décision, pas un oubli - et pour un fichier non signé, un avertissement est exactement ce que Windows doit afficher.

SmartScreen tient aussi compte de la réputation : plus il y a de personnes qui exécutent le même fichier sans problème, plus vite Windows le reconnaît et plus vite l'avertissement cesse. Chaque version est un nouveau fichier qui repart de zéro - c'est pourquoi l'avertissement peut revenir après une mise à jour, et pourquoi il s'estompe à mesure qu'une version est utilisée.

La version du Microsoft Store est signée par Microsoft et n'affiche pas cet écran. Chaque version publiée sur GitHub comporte aussi un fichier .sha256 à côté de chaque téléchargement : exécutez Get-FileHash -Algorithm SHA256 <file> dans PowerShell sur le fichier que vous avez téléchargé, et le résultat doit correspondre à la valeur indiquée dans ce fichier.

Sur quoi cliquer

Sur l'écran « Windows a protégé votre ordinateur » :

  1. Cliquez sur « Informations complémentaires » (More info), sous le message.
  2. Vérifiez que le nom du fichier est bien celui du fichier STREAMS Player que vous avez téléchargé, puis cliquez sur « Exécuter quand même » (Run anyway).

C'est tout - le programme d'installation, ou l'application depuis le ZIP, démarre normalement. Vous n'avez jamais besoin de désactiver SmartScreen ni votre antivirus, et l'application elle-même n'a jamais besoin de droits d'administrateur.

« Voulez-vous autoriser cette application d'un éditeur inconnu à apporter des modifications à votre appareil ? »

Normalement, vous ne devriez pas voir cette demande. Par défaut, le programme d'installation installe pour vous seul, dans %LOCALAPPDATA%\Programs\StreamsPlayer, et n'a pas besoin de droits d'administrateur pour cela. S'il vous demande comment installer, choisissez « Installer seulement pour moi (recommandé) ».

Windows n'affiche cette demande que si vous choisissez « Installer pour tous les utilisateurs ». Le programme d'installation utilise alors les droits d'administrateur pour exactement trois choses :

  • copier le programme dans le dossier Programmes (Program Files), pour que chaque compte de ce PC puisse le lancer ;
  • ajouter STREAMS Player au menu Démarrer de chaque compte, et au bureau partagé si vous avez coché cette option ;
  • l'enregistrer auprès de Windows comme application installée, pour qu'il puisse être supprimé plus tard.

Une seule action supprime les trois à la fois : Paramètres > Applications > Applications installées (Applications et fonctionnalités sous Windows 10) > STREAMS Player > Désinstaller. Si vous préférez ne pas accorder de droits d'administrateur, cliquez sur « Non » et relancez le programme d'installation avec « Installer seulement pour moi ».

Si votre antivirus bloque le fichier

Certains antivirus se méfient des fichiers nouveaux et non signés. Si le vôtre met STREAMS Player en quarantaine, restaurez-le et ajoutez une exception pour son seul dossier - %LOCALAPPDATA%\Programs\StreamsPlayer pour le programme d'installation, ou le dossier dans lequel vous avez décompressé le ZIP. Une exception pour ce seul dossier suffit, et vous pouvez la retirer à tout moment ; ne désactivez pas votre antivirus.

Ce que STREAMS Player ne fait jamais

  • Il n'a jamais besoin de droits d'administrateur pour s'installer ou fonctionner, ne s'ajoute jamais au démarrage de Windows et n'installe aucun service en arrière-plan.
  • Il n'a ni compte, ni publicité, ni analyse d'usage, ni télémétrie, ni service géré par l'auteur par lequel transiteraient vos données.
  • Il ne se connecte que sur votre action, et uniquement à ce dont cette action a besoin : le catalogue public de flux et son pack d'aperçus facultatif sur GitHub, le fournisseur d'un flux que vous lisez, enregistrez ou prévisualisez, un téléphone ou une montre équipés de FastMediaSorter sur votre propre réseau, et les bibliothèques FFmpeg facultatives si vous les demandez dans « Outils ». Un programme TV n'est téléchargé que depuis une adresse que vous saisissez vous-même, et seulement quand vous appuyez sur « Télécharger le programme ».
  • Il ne télécharge jamais le catalogue de lui-même - une actualisation n'a lieu que lorsque vous la demandez.
  • Il n'envoie jamais vos données ni vos journaux nulle part de lui-même. « Envoyer les journaux à l'auteur » dans « Outils » se contente de préparer une archive et un message dans votre propre logiciel de messagerie ; rien ne part tant que vous n'y avez pas appuyé sur Envoyer.
  • Le désinstaller ne supprime jamais vos chaînes, vos épingles ni votre historique - ils restent dans %LOCALAPPDATA%\StreamsPlayer jusqu'à ce que vous supprimiez ce dossier vous-même.
