STREAMS Player · Support

Something not working? Here is how to report it.

STREAMS Player is made by an independent developer. This page says what to put in a report, where to send it, and what you can expect back.

Report a bug

Open an issue on GitHub. The form asks for what happened, the steps that lead to it, the version of STREAMS Player and the version of Windows. You find the app version on the About page in the Settings window. If a particular channel is involved, name it. An issue needs a free GitHub account; if you have none, use the address further down this page.

Report on GitHub

Report a problem with the logs

Open Settings from the gear button in the header, or from the Library settings entry of the Operations menu, and press Send logs to the author on the About page. The app packs the diagnostic logs of the last ten launches with a short summary of your version, Windows and settings into the folder chosen in the Frames folder setting on the Files page of Settings (Downloads if none is chosen), then opens your mail program with the message ready. The confirmation shows the complete path and can open that folder when you ask; you attach the archive and press Send.

A channel stops playing

The catalog is a public list of streams that other people run: radio stations, broadcasters, camera owners. STREAMS Player keeps their addresses on your device and, as the privacy page says, connects to the network only when you act; the streams themselves stay with whoever runs them, so a stream can move, change format, become available only in another region or go off the air for good, and the catalog changes over time. When a channel fails, the Stream unavailable window may offer Retry, Copy report, Hide (Delete, for a channel you added or imported yourself) and Keep. Which of them appear depends on the failure: Retry is left out for an address the app cannot play at all, and Hide or Delete is left out when there is no network connection, because the channel was then never reached. Retry tries again, or you can simply open another channel; Hide takes the channel out of your list, and you can bring it back: press Hidden on the Library page in Settings, then Unhide next to the channel; Copy report puts a short note on your clipboard to paste into an issue, and the app sends nothing. Import channels from the internet, in the Operations menu, downloads the current catalog, and only when you ask. A stream that is gone is not a fault in the app, and no fix is promised.

Windows warned you

If Windows stopped the installer with a “Windows protected your PC” screen, that is Microsoft Defender SmartScreen reacting to a file it does not know yet. It is not a report of something found inside the file. The install help page says what the screen means and exactly what to click.

Write to the author directly

If you would rather not use GitHub, or the matter should not be public, write to sza@ukr.net. Security reports belong here and not in a public issue. So do diagnostic logs, which name the streams you played.

What to expect

This is an independent project. The author answers when time allows; no response time is promised, and neither is a fix for every report. A report that names the version, the steps and the channel is easier to act on.
