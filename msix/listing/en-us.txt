@@ShortDescription
Browse internet radio and live video in a focused Windows player with a curated catalog, local favorites, live grid previews, and no required account or advertising.

@@Description
STREAMS Player is an independent Windows desktop application for browsing and playing internet radio, live video, and RTSP stream addresses.

Explore a curated catalog by category, language, country, or media type. Search and sort channels, pin the streams you use most, or add a direct stream URL manually. Audio plays in the main window, while video opens in a dedicated window with always-on-top and borderless fullscreen controls.

Choose a compact list or a visual grid. Grid mode can capture current thumbnails for visible HTTP(S) video streams; tile size and automatic thumbnail updates are controlled in Settings. The complete interface is available in thirteen languages, with mirrored right-to-left layout for Arabic and Urdu.

Record the live video or radio you are playing to a file without interrupting it. Shrink the catalog to a compact radio panel while a station plays. Listen to a live audio broadcast from a FastMediaSorter phone or watch, directly over your local network. Keep channels in your own collections, return to them from a private listening history, and import or export M3U playlists.

Catalog downloads happen only when you choose Import channels from the internet. STREAMS Player requires no account and has no advertising, analytics, or telemetry. Catalog state, manual entries, favorites, playback marks, settings, and cached thumbnails stay in your Windows profile.

Playback compatibility depends on the stream provider, network availability, protocol, and the media codecs supported by the included LibVLC components. STREAMS Player does not host or control third-party stream content.

STREAMS Player is open source under the MIT License. The optional Exchange source in Library settings connects to your own server over TLS. Enrollment sends your login, password or pairing code, device identity, product version and receiver capabilities. Later connections use the device identity and device token. It holds one control connection with keepalives and reconnects while enabled; disabling it closes the connection. Import a connection string or file in Library settings, or paste or drop it in the main window. It carries the server address and an optional certificate fingerprint, with no secret. Reading it only fills the form. Check the address before entering your password or pairing code for each enrollment; neither is kept. A supplied fingerprint must match, with no trust prompt. Without one, you approve the server fingerprint before enrollment; later certificate changes need your approval. No local agent or second program is needed. The password and pairing code are discarded. The account, token and certificate pin are protected for your Windows user in a separate file; removing the account forgets them. Diagnostic bundles omit that file and redact account values. Exchange connections begin only after your explicit source setup.

Broadcasting: the application can send the audio of this PC - a microphone you choose and the sound the PC is playing - live to the exchange server of your own account, only when you allow it in Settings and start a source yourself; it is off until then, nothing is captured while it is off, and a visible indicator with a stop is shown while a source is live. Listeners connect over your local network, if you enable it, or through your exchange server. You can limit the number of listeners. Each separately sent copy uses this PC’s upload; the exchange server can distribute one copy to many listeners. A broadcast link or file you hand out carries the title, addresses and keys that open the broadcast. Treat it as a secret and share it only with people you choose. The account directory carries those keys in an encrypted box.

In the 64-bit viewer, right-click a video or audio file or its folder and choose Broadcast. Share Manager exports a .spres file, QR code or quick link for import in StreamsPlayer. A folder is one playlist channel with a frozen list; Refresh replaces that list and Revoke stops its link. The HTTP gateway has its own switch, off by default. Each token grants read-only access to one broadcast and normally expires after 24 hours. HTTP is unencrypted: share the document privately and keep internet access off unless you need it.
