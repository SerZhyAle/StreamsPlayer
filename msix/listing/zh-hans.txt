@@ShortDescription
在一款专注的 Windows 播放器中浏览网络广播和直播视频，配有精选目录、保存在本地的置顶频道、网格实时预览和简体中文界面，无需强制账户，没有广告。

@@Description
STREAMS Player 是一款独立的 Windows 桌面应用，用于浏览和播放网络广播、直播视频和 RTSP 流地址。

按类别、语言、国家/地区或媒体类型浏览精选目录。搜索并排序频道，把最常用的流置顶，或手动添加直接的流地址 URL。音频在主窗口播放，视频则在独立窗口中打开，并带有总在最前和无边框全屏控件。

可以选择紧凑列表或可视网格。在网格模式下，应用可以为可见的 HTTP(S) 视频流抓取当前缩略图；图块大小和缩略图的自动更新在“设置”中控制。完整界面提供十三种语言，阿拉伯语和乌尔都语采用从右到左的镜像布局。

将正在播放的直播视频或广播录制为文件，播放不会中断。电台播放时可把目录缩成一个紧凑的电台面板。通过您的本地网络，直接收听运行 FastMediaSorter 的手机或手表发出的音频直播。把频道放进您自己的收藏集，从私人收听历史中回到它们，并导入或导出 M3U 播放列表。

只有在您选择“从互联网导入频道”时才会下载目录。STREAMS Player 不强制要求账户，没有广告、分析统计或遥测。目录状态、手动添加的条目、置顶的频道、播放标记、设置和缓存的缩略图都保存在您的 Windows 用户配置文件中。

播放兼容性取决于流提供方、网络可用性、协议，以及内置 LibVLC 组件所支持的媒体编解码器。STREAMS Player 不托管也不控制第三方的流内容。

STREAMS Player 是遵循 MIT 许可证的开源软件。 资料库设置中的可选交换来源通过 TLS 连接到您自己的服务器。注册时仅发送一次登录名和密码或配对码，之后发送设备身份、产品版本、接收能力及设备令牌。启用时保持一个控制连接，发送保活消息并自动重连；禁用后关闭连接。在媒体库设置中导入连接字符串或文件，也可粘贴或拖放到主窗口。它包含服务器地址和可选证书指纹，不含秘密。读取仅填写表单。每次注册输入密码或配对码前请检查地址；两者均不保存。提供的指纹必须匹配，无需信任提示。没有指纹时须在注册前批准服务器指纹；后续证书变更需要批准。无需本地代理或其他程序。密码和配对码随后清除。账户、令牌及证书指纹保存在单独文件中，仅供当前 Windows 用户解密；移除账户后清除这些内容。诊断压缩包不包含此文件，并隐藏账户信息。只有您明确设置此来源后才会连接交换服务器。

广播：本应用可以将此电脑的四个来源直播发送 - 您选择的麦克风、电脑正在播放的声音、您选择的一整个显示器和您选择的一个摄像头，其中屏幕和摄像头在同一次广播中各可选择性地携带一路声音（麦克风或系统声音） - 发送到您自己账户的交换服务器或通过您的本地网络，且仅当您在设置中允许并亲自启动每个来源时才会发送；在此之前它是关闭的，关闭时不会采集任何内容，而当某个来源正在直播时，会显示一个带有停止按钮的可见指示器，并显示正在直播的显示器或摄像头的名称。视频为 H.264，最高 1280x720，每秒 30 帧，约 2 Mbit/s，由 Windows 自带的编码器生成；不添加任何组件。所选显示器上的所有内容都会被发送，包括通知和密码，受 Windows 保护的内容可能显示为空白。仅以访客身份登录某服务器的电脑不会广播。听众通过您启用的本地网络或交换服务器连接。您可以限制听众数量。本地网络上的每位听众和每条隧道都会占用此电脑的上传带宽；通过服务器的中继，此电脑只需为所有听众发送一份数据。您交给其他人的广播链接、文件或二维码包含标题、地址和打开广播的密钥，但绝不包含密码。您在设置中选择密码的生成方式：每次广播随机生成（默认）、由您设置（1 到 64 个字符，只保存在您 Windows 账户的 Windows 机密存储中），或无密码，此时任何拿到链接的人都可以观看和收听。广播期间更改会立即使之前的密码失效。实时指示器的“分享”菜单可复制链接、复制密码、将链接显示为供手机扫描的二维码，并保存描述文件。请将链接视为机密，仅与您选择的人分享。账户目录将这些密钥放在加密盒中。

在 64 位查看器中，右键点击视频、音频文件或其文件夹并选择广播。Share Manager 导出 .spres 文件、二维码或快速链接，供 StreamsPlayer 导入。文件夹成为一个包含固定播放列表的频道；刷新会替换列表，撤销会停用链接。HTTP 网关有独立开关，默认关闭。每个令牌只允许读取一个广播，通常在 24 小时后过期。HTTP 未加密：请私下分享文档，仅在需要时启用互联网访问。

Google 登录为可选功能，仅请求 drive.appdata 权限。Google 通过 accounts.google.com、oauth2.googleapis.com 和 www.googleapis.com 接收登录及 API 请求。仅读取隐藏应用数据中的设备名称（fmsx-device-*）和广播公告（fmsx-broadcast-*）。此电脑在广播期间写入和更新自己的公告，并在结束时删除；媒体从不通过 Drive 传输。仅在列表窗口打开且未最小化时轮询目录。刷新令牌受当前 Windows 用户保护。退出会删除令牌并请求 Google 撤销访问；撤销失败会明确提示。公告保存在您的 Google 账号中，不额外进行端到端加密。
