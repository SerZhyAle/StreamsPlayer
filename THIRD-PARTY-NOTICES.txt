4. Bundled stream catalog snapshot (data, not code)
   File: catalog-snapshot.zip, embedded in StreamsPlayer.Core
-----------------------------------------------------------------------
A copy of the published FastMediaSorter stream bank travels inside this
application so the channel list can be filled without a network connection.
It is data - stream addresses, station names and icons - and carries no
executable code and no license of its own beyond the bank's own terms.

Taken from the published release asset:
  https://github.com/SerZhyAle/FastMediaSorter_mob_v2/releases/download/delivery-so-v1/stream-catalog.zip

The exact source address and the date the copy was taken are recorded inside
the archive itself (snapshot.json) and shown in the application when the copy
is used, so a user is never told bundled data is a fresh download.

The stream addresses are the publishers' own public endpoints; this
application redistributes the list, not the streams. The copy is refreshed
only when the application is released, never between releases.
